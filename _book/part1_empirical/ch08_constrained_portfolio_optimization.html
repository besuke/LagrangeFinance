第I-8章 制約付きポートフォリオ最適化とバックテスト

本章では、これまでに作成した株式リターン履歴を用いて、制約付きポートフォリオ最適化を実装する。第5章で確認した平均分散法を出発点とし、最小分散、平均分散、最大リターン、最大シャープレシオ、最小期待ショートフォール、リスク・バジェッティング、目標リターン、目標リスクへと拡張する。

計算にはGaussQuantのポートフォリオAPIを用いる。これにより、最適化問題そのものを本章内で再実装するのではなく、投資ユニバース、リターンデータ、制約条件、最適化手法を分離して記述できる。

株式リターン履歴
        ↓
投資ユニバース
        ↓
portfolio_spec_GQL()
        ↓
制約条件
        ↓
portfolio_optimize_GQL()
        ↓
最適ウェイト
        ↓
Efficient Frontier
        ↓
バックテスト

I-8.1 ポートフォリオ最適化の基本

銘柄数を \(N\)、ポートフォリオ・ウェイトを \(\boldsymbol{w}\)、期待リターンを \(\boldsymbol{\mu}\)、分散共分散行列を \(\boldsymbol{\Sigma}\) とする。

\[ \mu_p=\boldsymbol{w}^{\top}\boldsymbol{\mu}, \qquad \sigma_p^2=\boldsymbol{w}^{\top}\boldsymbol{\Sigma}\boldsymbol{w} \]

完全投資かつロングオンリー、銘柄別上限を \(w_{\max}\) とすると、

\[ \sum_{i=1}^{N}w_i=1, \qquad 0\leq w_i\leq w_{\max} \]

である。GaussQuantでは、これらを目的関数の内部に直接書き込まず、ポートフォリオ仕様と制約条件として登録する。

I-8.2.3 GaussQuant形式への変換

portfolio_optimize_GQL() はlong形式のリターンデータを受け取る。本章では firm_ID を資産名、month_ID を時点として利用する。

tbl_returns_GQL <- tbl_return_history |>
  filter(firm_ID %in% as.integer(vec_assets)) |>
  transmute(
    date = month_ID,
    asset = as.character(firm_ID),
    return = as.numeric(return)

  arrange(date, asset)

第7章で推定した期待リターンは投資ユニバースの形成や結果比較に利用できる。一方、現行の portfolio_optimize_GQL() は入力されたリターン履歴から標本平均と分散共分散行列を推定する。本章では、このGaussQuantの計算仕様に合わせてリターン履歴を直接入力する。

I-8.5 期待ショートフォールとリスク・バジェッティング

I-8.5.1 期待ショートフォール

損失を \(L\)、信頼水準を \(\alpha\) とする。期待ショートフォールは、市場VaRを超えるテール損失の平均として扱う。

confidence_level <- 0.95

result_minimum_ES <- GaussQuant::portfolio_optimize_GQL(
  tbl_returns = tbl_returns_GQL,
  portfolio = portfolio_spec,
  method = "minimum_ES",
  confidence_level = confidence_level
)

期待ショートフォールは次章の市場リスク計測で詳しく扱う。本章では、分散だけでなく損失分布のテールを目的関数にできることを確認する。

I-8.5.2 リスク・バジェッティング

ポートフォリオ分散への資産 \(i\) の寄与は、

\[ RC_i=w_i(\boldsymbol{\Sigma}\boldsymbol{w})_i \]

で表される。ここでは各資産の目標リスク寄与を等しく設定する。

risk_budget <- rep(
  1 / length(vec_assets),
  length(vec_assets)
)

result_risk_budget <- GaussQuant::portfolio_optimize_GQL(
  tbl_returns = tbl_returns_GQL,
  portfolio = portfolio_spec,
  method = "risk_budget",
  risk_budget = risk_budget
)

各手法は同じ「最適ポートフォリオ」を求めているのではない。最小分散は分散、最大リターンは期待リターン、最大シャープレシオはリスク当たり超過リターン、最小ESはテール損失、リスク・バジェッティングはリスク寄与の配分をそれぞれ最適化している。

I-8.8 Efficient Frontier

目標期待リターンを変化させながら最小分散ポートフォリオを求めることでEfficient Frontierを構成できる。本節では、GaussQuantの target_return 最適化を繰り返し、専用の portfolio_frontier_GQL() を導入する前段階として最適化APIとEfficient Frontierの関係を確認する。

vec_target_returns <- seq(
  minimum_return,
  maximum_return,
  length.out = 31
)[1:30]

最大リターン点そのものは result_maximum_return で別途計算済みである。したがって、target_return によるフロンティア計算では最大リターン境界を1点だけ除外し、境界上での数値的な退化を避ける。

lst_frontier_results <- purrr::map(
  vec_target_returns,
  \(target_value) {
    GaussQuant::portfolio_optimize_GQL(
      tbl_returns = tbl_returns_GQL,
      portfolio = portfolio_spec,
      method = "target_return",
      target_return = target_value
    )
  }
)

tbl_efficient_frontier <- purrr::map2_dfr(
  lst_frontier_results,
  vec_target_returns,
  \(result, target_value) {
    result$statistics |>
      filter(
        metric %in% c(
          "expected_return",
          "volatility",
          "sharpe_ratio"
        )
      ) |>
      select(metric, value) |>
      pivot_wider(
        names_from = metric,
        values_from = value
      ) |>
      mutate(
        target_return = target_value,
        .before = 1
      )
  }
)
plot_efficient_frontier <- ggplot(
  tbl_efficient_frontier,
  aes(
    x = volatility,
    y = expected_return
  )
) +
  geom_line() +
  geom_point() +
  labs(

    y = "Expected Return"

show_plot_LFL(plot_efficient_frontier)

I-8.10 アウト・オブ・サンプル評価

最適化の結果は推定期間内の目的関数だけで評価すべきではない。推定期間で求めたウェイトをその後のリターンへ適用し、アウト・オブ・サンプルで評価する。

tbl_next_year_returns <- tbl_return_history |>
  filter(
    firm_ID %in% as.integer(vec_assets),
    lubridate::year(month_date) == rebalance_year + 1
  ) |>
  transmute(
    month_date,
    asset = as.character(firm_ID),
    return = as.numeric(return)
  )

最大シャープレシオ・ポートフォリオを例として評価する。

tbl_backtest <- tbl_next_year_returns |>
  inner_join(
    result_maximum_sharpe$weights,
    by = "asset"
  ) |>
  group_by(month_date) |>
  summarise(
    portfolio_return = sum(
      weight * return,
      na.rm = TRUE
    ),
    .groups = "drop"
  ) |>
  arrange(month_date) |>
  mutate(
    wealth_index = cumprod(
      1 + portfolio_return
    )
  )
plot_backtest <- ggplot(
  tbl_backtest,
  aes(
    x = month_date,
    y = wealth_index
  )
) +
  geom_line() +
  labs(
    x = NULL,
    y = "Wealth Index"
  )

show_plot_LFL(plot_backtest)
tbl_backtest_summary <- tbl_backtest |>
  summarise(
    observations = n(),
    cumulative_return = prod(1 + portfolio_return) - 1,
    mean_return = mean(portfolio_return),
    volatility = sd(portfolio_return),
    minimum_return = min(portfolio_return),
    maximum_return = max(portfolio_return)
  )

show_table_LFL(tbl_backtest_summary)
#> # A tibble: 1 × 6
#>   observations cum_retur mea_retur volatility min_retur max_retur
#>          <int>     <dbl>     <dbl>      <dbl>     <dbl>     <dbl>
#> 1           12   0.26165  0.020890   0.054658 -0.070265   0.13034

本章では、ポートフォリオ最適化をGaussQuantの統一APIで実装した。最適化ロジックを章内に直接記述する方法から、ポートフォリオ仕様、制約条件、最適化手法を分離する構成へ変更した。

最小分散、平均分散、最大リターン、最大シャープレシオに加えて、期待ショートフォール、リスク・バジェッティング、目標リターン、目標リスクを同じAPIで扱うことで、ポートフォリオ最適化を一般的なリスク配分問題として捉えることができる。

また、目標リターンを連続的に変化させることでEfficient Frontierを構成し、最小分散点と最大シャープレシオ点を同一平面上で確認した。

次章では、ポートフォリオの損失分布そのものに焦点を移し、市場VaRと期待ショートフォールを中心に市場リスク計測を扱う。
