第I-9章 市場リスクと市場VaR

本章では、市場リスク管理の中心的な尺度である市場Value at Risk（市場VaR）を扱う。最初に、市場VaRを中心として発展してきた市場リスク規制を、バーゼルII、バーゼル2.5、Fundamental Review of the Trading Book（FRTB）という流れから整理する。そのうえで、分散共分散法、ヒストリカル法、モンテカルロ法による市場VaRを実装し、期待ショートフォール（ES）、リスク寄与度、バックテストへ進む。

本章の目的はFRTBの標準的方式を再現することではない。FRTBを市場リスク管理の歴史的背景として位置づけ、市場VaRとESの考え方を、Rによるデータ処理とシミュレーションを通して理解することにある。

I-9.1 FRTBとは何か

1990年代以降、金融機関の市場リスク管理では市場VaRが広く利用されるようになった。市場VaRは、一定の保有期間と信頼水準のもとで、ポートフォリオに生じ得る損失を一つの数値として表現する。この簡潔さから、市場VaRは内部リスク管理だけでなく、規制上の市場リスク計測にも組み込まれていった。

しかし、2007年から2008年にかけて進行した世界金融危機は、従来の市場リスク管理の限界を明らかにした。特にトレーディング勘定では、危機前に想定されていた水準を大きく上回る損失が発生した。市場流動性の急激な低下、信用スプレッドの拡大、証券化商品の価格下落、複数のリスク要因の同時変動などが重なり、平常時の過去データを中心に推定されたリスク尺度だけでは、危機時の損失を十分に捉えられない場合があることが認識された。

さらに、大規模金融機関の経営危機は金融システム全体へ波及し得るため、各国では金融システム安定化のための公的支援が実施された。この経験は「Too Big To Fail」をめぐる議論を強め、個別金融機関の内部管理だけではなく、金融システム全体の安定性を意識した規制改革を促すことになった。

危機への比較的早い対応が、一般にバーゼル2.5と呼ばれる市場リスク規制の強化である。従来の市場VaRに加えて、深刻な市場ストレス期を反映した stressed VaR が導入され、トレーディング勘定の信用リスクについても追加的な資本賦課が強化された。

ただし、これは危機への対応の終点ではなかった。トレーディング勘定と銀行勘定の境界、流動性の異なるリスク要因の扱い、内部モデルの比較可能性、市場VaRが損失分布の裾の大きさを直接表現しないことなど、より構造的な問題が残った。

そこでバーゼル銀行監督委員会は、市場リスク規制を根本から見直すFRTBを策定した。2016年に市場リスクの最低所要自己資本に関する基準が公表され、2019年に改訂された最終基準が公表された。

FRTBの重要な特徴の一つが、内部モデル方式において中心的なリスク尺度を市場VaRから期待ショートフォールへ移したことである。市場市場VaRが損失分布のある分位点を示すのに対し、ESはその分位点を超えた領域の損失を平均する。そのため、極端な市場変動が発生した場合の損失の大きさをより直接的に捉えることができる。

したがって、市場リスク計測の発展は概念的には次のように整理できる。

VaR
  ↓
世界金融危機
  ↓
stressed VaR（バーゼル2.5）
  ↓
FRTB
  ↓
期待ショートフォール

日本ではバーゼルIII最終化に伴う市場リスク規制が段階的に導入され、国際統一基準金融機関および内部モデルを採用する国内基準金融機関には2024年3月31日から、内部モデルを採用しない国内基準金融機関等には2025年3月31日から適用されている。

本章ではFRTBの標準的方式の詳細な資本計算には立ち入らない。ここからは、FRTBに至る市場リスク管理の基礎となった市場VaRそのものを理解する。

I-9.2 市場VaRとは何か

時点 \(t\) のポートフォリオ価値を \(V_t\) とすると、1期間の損益は

\[ \mathrm{PnL}_{t+1}=V_{t+1}-V_t \]

である。市場リスク管理では損失を正の値として扱うため、損失変数を

\[ L_{t+1} = -\mathrm{PnL}_{t+1} = V_t-V_{t+1} \]

と定義する。

信頼水準 \(\alpha\) における市場VaRは、損失分布の \(\alpha\) 分位点として

\[ \mathrm{VaR}_{\alpha} = \inf\left\{ l: P(L\le l)\ge\alpha \right\} \]

と定義される。

例えば95%市場VaRが1億円であるとは、モデルと観測期間を前提としたとき、損失が1億円以下となる確率が95%であることを意味する。残り5%の領域では1億円を超える損失が発生し得る。市場VaRそのものは、その5%の領域で損失がどこまで拡大するかを示さない。

本章では第8章と同じ株式リターン履歴を利用する。データはParquet形式で保存されているため、Arrowを通して読み込む。

I-9.4 分散共分散法による市場VaR

最も基本的な市場VaR計算法は、ポートフォリオ・リターンが正規分布に従うと仮定する分散共分散法である。

ポートフォリオ・リターンを

\[ R_p \sim N(\mu_p,\sigma_p^2) \]

とすると、信頼水準 \(\alpha\) の市場VaRは

\[ \mathrm{VaR}_{\alpha} = -\mu_p+\Phi^{-1}(\alpha)\sigma_p \]

で与えられる。

confidence_level <- 0.95

mean_return <- mean(
  tbl_portfolio_returns$portfolio_return,
  na.rm = TRUE
)

volatility <- sd(
  tbl_portfolio_returns$portfolio_return,
  na.rm = TRUE
)

gaussian_var <- -mean_return +
  qnorm(confidence_level) * volatility

tbl_gaussian_var <- tibble(
  method = "Gaussian",
  confidence_level = confidence_level,
  VaR = gaussian_var
)

show_table_LFL(tbl_gaussian_var)
#> # A tibble: 1 × 3
#>   method   con_level      VaR
#>   <chr>        <dbl>    <dbl>
#> 1 Gaussian      0.95 0.064805

分散共分散法は高速で解釈しやすい。一方、正規分布という仮定によって、歪度やファットテールを十分に表現できない場合がある。

I-9.5 ヒストリカル法による市場VaR

ヒストリカル市場VaRでは、特定の確率分布を仮定せず、実際に観測された損失分布から分位点を求める。

\[ \mathrm{VaR}_{\alpha} = Q_\alpha(L) \]

historical_var <- quantile(
  tbl_portfolio_losses$loss,
  probs = confidence_level,
  na.rm = TRUE,
  names = FALSE,
  type = 7
)

tbl_historical_var <- tibble(
  method = "Historical",
  confidence_level = confidence_level,
  VaR = historical_var
)

show_table_LFL(tbl_historical_var)
#> # A tibble: 1 × 3
#>   method     con_level      VaR
#>   <chr>          <dbl>    <dbl>
#> 1 Historical      0.95 0.066008

ヒストリカル法には分布仮定が不要という利点がある。しかし、将来発生する損失が過去の観測範囲に強く依存するという制約がある。

I-9.6 モンテカルロ法による市場VaR

モンテカルロ法では、確率モデルから多数の市場シナリオを生成し、それぞれのシナリオでポートフォリオ損益を計算する。

ここでは正規分布モデルを用いる。シミュレーション規模が大きくなることを想定し、furrr により並列化できる構造とする。

future::plan(
  future::multisession,
  workers = max(
    1,
    future::availableCores() - 1
  )
)
set_random_seed_LFL(20260918)

n_scenarios <- 100000
n_batches <- 20
n_per_batch <- n_scenarios / n_batches

lst_simulated_returns <- furrr::future_map(
  seq_len(n_batches),
  \(batch_id) {
    tibble(
      simulated_return = rnorm(
        n = n_per_batch,
        mean = mean_return,
        sd = volatility
      )
    )
  },
  .options = furrr::furrr_options(
    seed = TRUE
  )
)

tbl_monte_carlo <- bind_rows(
  lst_simulated_returns
) |>
  mutate(
    loss = -simulated_return
  )
monte_carlo_var <- quantile(
  tbl_monte_carlo$loss,
  probs = confidence_level,
  na.rm = TRUE,
  names = FALSE
)

tbl_monte_carlo_var <- tibble(
  method = "Monte Carlo",
  confidence_level = confidence_level,
  VaR = monte_carlo_var
)

show_table_LFL(tbl_monte_carlo_var)
#> # A tibble: 1 × 3
#>   method      con_level      VaR
#>   <chr>           <dbl>    <dbl>
#> 1 Monte Carlo      0.95 0.064715

計算終了後は並列バックエンドを通常状態へ戻す。

I-9.8 期待ショートフォール

市場VaRの重要な限界は、市場VaRを超えた領域の損失の大きさを表現しないことである。

期待ショートフォール（ES）は、損失が市場VaRを超えるテール領域の平均損失として直感的に理解できる。

\[ ES_\alpha = E[L\mid L\ge \mathrm{VaR}_{\alpha}] \]

実証分布では次のように計算できる。

historical_es <- tbl_portfolio_losses |>
  filter(loss >= historical_var) |>
  summarise(
    ES = mean(loss, na.rm = TRUE)
  ) |>
  pull(ES)

tbl_var_es <- tibble(
  measure = c("VaR", "期待ショートフォール"),
  value = c(
    historical_var,
    historical_es
  )
)

show_table_LFL(tbl_var_es)
#> # A tibble: 2 × 2
#>   measure                 value
#>   <chr>                   <dbl>
#> 1 VaR                  0.066008
#> 2 期待ショートフォール 0.087030
plot_var_es <- tbl_var_es |>
  ggplot(
    aes(
      x = measure,
      y = value
    )
  ) +
  geom_col() +
  labs(
    x = NULL,
    y = "Loss"
  )

show_plot_LFL(plot_var_es)

通常、同一の信頼水準ではESは市場VaR以上となる。市場VaRがテール領域への入口を示すのに対し、ESはその先で平均的にどの程度の損失が生じるかを表す。

I-9.9 市場VaRのリスク寄与度

ポートフォリオ全体の市場VaRだけでは、どの資産がリスクを生み出しているかは分からない。分散共分散法では、市場VaRを各資産の寄与に分解する考え方へ発展させることができる。

ポートフォリオ・ボラティリティを

\[ \sigma_p = \sqrt{ w^\top \Sigma w } \]

とすると、資産 \(i\) のボラティリティに対する限界寄与は

\[ \frac{\partial \sigma_p}{\partial w_i} = \frac{(\Sigma w)_i}{\sigma_p} \]

である。

成分リスク寄与は

\[ RC_i = w_i \frac{(\Sigma w)_i}{\sigma_p} \]

となり、

\[ \sum_i RC_i=\sigma_p \]

が成立する。この考え方は、第8章のリスク・バジェッティングと直接つながっている。

I-9.10 市場VaRバックテスト

市場VaRモデルは計算して終わりではない。実際の損失が市場VaRを超えた回数を観測し、モデルが想定した信頼水準と整合しているかを確認する必要がある。

時点 \(t\) の損失を \(L_t\)、市場VaRを \(\mathrm{VaR}_t\) とすると、超過指標を

\[ I_t = \mathbf{1} \left( L_t>\mathrm{VaR}_t \right) \]

と定義する。

ここでは説明を単純にするため、全期間から求めたヒストリカル市場VaRに対する超過回数を確認する。

tbl_var_backtest <- tbl_portfolio_losses |>
  mutate(
    VaR = historical_var,
    exception = loss > VaR
  )

tbl_var_backtest_summary <- tbl_var_backtest |>
  summarise(
    observations = n(),
    exceptions = sum(exception, na.rm = TRUE),
    exception_rate = mean(exception, na.rm = TRUE),
    expected_exception_rate =
      1 - confidence_level
  )

show_table_LFL(
  tbl_var_backtest_summary
)
#> # A tibble: 1 × 4
#>   observations exceptions exc_rate exp_rate
#>          <int>      <int>    <dbl>    <dbl>
#> 1           71          4 0.056338 0.050000

実務的なバックテストでは、各時点で利用可能であった過去データのみを使って市場VaRを推定し、翌期の実現損失と比較する。したがって、ローリング・ウィンドウによるVaR推定へ拡張することが重要である。

I-9.11 FRTBと期待ショートフォール

世界金融危機後の市場リスク規制は、単に市場VaRのパラメータを変更するだけではなく、市場ストレス、流動性、モデル化可能性、トレーディング勘定の境界などを含めて再設計された。

FRTBの内部モデル方式では期待ショートフォールが中心的な市場リスク尺度となる。これは「市場VaRが誤っていてESが正しい」という単純な置き換えではない。市場VaRは現在でもリスク管理やバックテストを理解するうえで重要な基礎概念であり、ESを理解するためにも市場VaRの分位点という考え方が出発点となる。

本章で扱った流れは次のように整理できる。

市場リターン
    ↓
ポートフォリオ損益
    ↓
損失分布
    ├─ Gaussian 市場VaR
    ├─ Historical 市場VaR
    └─ Monte Carlo 市場VaR
              ↓
      期待ショートフォール
              ↓
      リスク寄与度
              ↓
        バックテスト
              ↓
       FRTBへの接続

第10章では、市場価格の変動ではなく企業のデフォルトによって生じる信用損失を扱う。One-Factor Gaussianモデルを用いて相関したデフォルトを生成し、ポートフォリオ損失分布から信用VaRを計算する。

市場VaRと信用VaRは対象とするリスクが異なる一方、

\[ \boxed{ \text{リスク要因} \rightarrow \text{損失シナリオ} \rightarrow \text{損失分布} \rightarrow \text{テールリスク} } \]

という計算構造を共有している。この構造はさらに第11章のCLOトランシェ評価へつながっていく。
