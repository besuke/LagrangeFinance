第II-2章 金利カーブ構築と債券先物の金利感応度

債券、金利スワップおよび金利オプションの評価では、将来キャッシュフローを現在価値へ換算するための金利期間構造が必要となる。金利期間構造は、満期ごとの金利を並べた単なる曲線ではない。市場で観測される預金金利、債券価格、FRA、OISレートおよびスワップレートなどから、各将来日の割引係数を整合的に推定した結果である。

同じ期間構造は、割引係数、ゼロ金利またはフォワード金利として表現できる。これらは相互に変換できるが、表現方法によってカーブの特徴の見え方は異なる。割引係数は現在価値計算に直接用いられ、ゼロ金利は評価日から各満期までの平均的な金利水準を示し、フォワード金利は将来の各区間に対応する限界的な金利を示す。

本章では、まず日本国債の長期時系列を用いて、イールドカーブが年限方向と時間方向の双方に変化することを確認する。次に、ゼロ金利ノードから単純なカーブを構築し、割引係数、ゼロ金利およびフォワード金利の関係を整理する。そのうえで補間方式の違い、預金と債券またはスワップを用いたブートストラップ、Implied Term Structure、金利シフトおよびカーブ検証へ進む。最後に、構築した金利期間構造が日本国債先物の受渡適格銘柄とCTD（Cheapest to Deliver）の選択へどのように影響するかを考察する。

II-2.1 イールドカーブおよび補間

第II-1章で述べたとおり、パーレート（スワップレート）、スポットレート（ゼロレート）、フォワードレートおよびディスカウントファクターの計算は、将来キャッシュフローを現在価値へ換算するための基礎であり、資本市場取引における最も重要な計算の一つである。

しかし、スポットレートやフォワードレートを市場から直接観測することはできない。実際に観測されるのは、国債価格、国債の複利利回り、預金金利、OISレートおよびスワップレートなど、取引可能な金融商品の価格またはレートである。したがって、これらの市場データから期間構造を構築する際には、異常値を適切に処理するとともに、限られた年限（tenor）の観測値をどのように補間し、安定したイールドカーブを構築するかが重要となる。

補間方法の選択は、単にグラフの見た目を滑らかにするためのものではない。補間されたカーブから割引係数、ゼロ金利およびフォワード金利が導出されるため、補間アルゴリズムの違いは金融商品の価格評価とリスク計測にも影響する。

そこで、まず実際の市場金利が年限方向と時間方向にどのように変化するかを確認する。以下では、財務省「Interest Rate Historical Data」の日本国債複利利回りを用いる。各観測日の離散的な年限データを自然スプラインで補間し、イールドカーブの長期的な変化を可視化する。また、同じデータを年限ごとの時系列へ組み替え、各tenorの金利水準が時間とともにどのように推移したかを確認する。

II-2.1.2 スプライン補間によるイールドカーブ

市場で観測される国債利回りは、1年、2年、5年、10年などの離散的な年限に限られる。そこで、観測日ごとに年限方向の自然スプライン補間を行い、0.1年刻みの連続的なカーブへ変換する。元の観測値を点、補間値を線として描くことで、観測された情報と補間によって推定された情報を区別する。

tbl_jgb_yield_spline <- tbl_jgb_yield |>
  dplyr::group_by(date) |>
  tidyr::nest() |>
  dplyr::mutate(
    tbl_spline = purrr::map(
      data,
      \(tbl_date) {
        spline_result <- stats::spline(
          x = tbl_date$tenor_years,
          y = tbl_date$compound_yield_pct,
          xout = seq(
            min(tbl_date$tenor_years),
            max(tbl_date$tenor_years),
            by = 0.1
          ),
          method = "natural"
        )

        tibble::tibble(
          tenor_years = spline_result$x,
          compound_yield_pct = spline_result$y
        )
      }
    )
  ) |>
  dplyr::select(
    date,
    tbl_spline

  tidyr::unnest(tbl_spline)

II-2.2 金利カーブの基礎

評価日を0、将来時点を \(t\) とし、時点 \(t\) に1を受け取るキャッシュフローの現在価値を \(D(0,t)\) とする。\(D(0,t)\) は割引係数である。連続複利のゼロ金利を \(z(0,t)\) とすると、両者の関係は次式で表される。

\[D(0,t) = \exp\left[-z(0,t)t\right]\]

したがって、割引係数からゼロ金利を求めると次式となる。

\[z(0,t) = -\frac{\log D(0,t)}{t}\]

二つの時点 \(t_1\) と \(t_2\) の間に適用される連続複利のフォワード金利を \(f(t_1,t_2)\) とすると、次式で求められる。

\[f(t_1,t_2) = -\frac{ \log\left[D(0,t_2)/D(0,t_1)\right] }{ t_2-t_1 }\]

割引係数、ゼロ金利およびフォワード金利は同じ期間構造を異なる方法で表している。ただし、補間方法の違いは、とくにフォワード金利の形状に強く表れる。

FRAは、将来の一定期間に適用される金利を直接観測する商品として、預金とスワップの間を接続するために用いられる。本章の実装では預金とスワップを用いるが、FRAを追加する場合も、各市場商品の理論価格が市場価格と一致するように同じブートストラップの枠組みへ組み込む。

II-2.5.1 Implied Term Structure

Implied Term Structureは、既存カーブが示す将来の割引関係を保ったまま、参照日を将来へ移した期間構造である。元のカーブの参照日を \(t_0\)、新しい参照日を \(t_1\)、将来日を \(t_2\) とすると、Implied Term Structureの割引係数は概念的に次式で表される。

\[D_{t_1}(t_2) = \frac{ D_{t_0}(t_2) }{ D_{t_0}(t_1) }\]

II-2.6 日本国債先物とCTD

日本の長期国債先物は、実在する特定銘柄ではなく、クーポン6%、償還期限10年の標準物を取引対象とする。満期時には、取引所が定めた受渡適格銘柄の中から売方が実際に受け渡す銘柄を選択する。各銘柄ではクーポンと残存期間が異なるため、標準物との価値の差をConversion Factor（CF）で調整する。

受渡価格の基本部分は次式で表される。

\[\text{Invoice Price} = F\times CF\]

ここで \(F\) は国債先物価格、\(CF\) はConversion Factorである。実際の受渡金額では、さらに受渡日の経過利子が加わる。

CTD（Cheapest-to-Deliver）は、単に現物価格が最も安い銘柄ではない。現物価格、Conversion Factor、保有期間中のクーポン、経過利子、資金調達費用を合わせて比較する必要がある。本節では、2026年9月10日を評価日、2026年12月20日を受渡日として、長期国債先物2026年12月限の受渡適格銘柄を比較する。

II-2.6.3 Gross Basis、Carry、Net Basis

Gross Basisは、現物クリーン価格とCFで調整した先物価格との差である。

\[\text{Gross Basis}_i = P_i-F\times CF_i\]

現物債を評価日から受渡日まで保有すると、クーポン収入と経過利子の変化を受け取る一方、現物購入資金にはFunding Costが発生する。本章では短期資金調達金利を1.23%とし、単純化したCash-and-Carryで比較する。

\[\text{Carry} = \text{Coupon Income} + (AI_T-AI_0) - \text{Funding Cost}\]

\[\text{Net Basis} = \text{Gross Basis}-\text{Carry}\]

  ) |>

II-2.7.1 6%標準物と金利水準

長期国債先物の標準物は、クーポン6%、償還期限10年である。市場金利が6%を下回り、かつイールドカーブが右上がりである場合、短いDuration側の銘柄が相対的に受渡しやすくなる傾向がある。

II-2.8 まとめ

本章では、財務省の日本国債複利利回りをpivot_longer()でlong形式へ変換し、年限方向のイールドカーブと時間方向の金利時系列を可視化した。離散的な観測点へ自然スプライン補間を適用することで、補間値は市場で直接観測された値ではなく、選択したアルゴリズムから推定された値であることを確認した。

続いて、割引係数、ゼロ金利およびフォワード金利を通じて金利期間構造を整理し、補間対象の違い、ブートストラップ、Implied Term Structure、カーブシフトおよび検証を扱った。とくにフォワード金利は、ゼロ金利では目立たない補間差を拡大して示すことがある。このため、カーブの妥当性は単一の表現だけで判断せず、入力商品の再現性と複数のカーブ表現を組み合わせて評価する必要がある。

後半では、日本の長期国債先物を対象として、6%クーポン・10年の標準物、Conversion Factor、Gross Basis、Carry、Net Basis、Implied Repo RateおよびCTDの関係を確認した。現物債の価格から複利利回りを逆算し、GaussQuantを用いてModified Durationを求めることで、クーポンと償還期限が金利感応度へ与える影響も同時に確認した。

さらに、現在の低金利・順イールド環境から、長期8%、短期9%の高金利・逆イールド環境へ市場条件を変化させ、同じ受渡適格銘柄を再評価した。Conversion Factorが固定されていても、市場金利の水準とイールドカーブの形状が変化すれば、Gross Basis、Net BasisおよびImplied Repo Rateの順位が変化し、CTDがスイッチし得る。

この結果は、国債先物のCTDが単なる銘柄属性ではなく、標準物の設計、市場のイールドカーブ、現物価格、資金調達コストおよび受渡条件の相対関係から決まることを示している。
