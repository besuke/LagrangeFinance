第II-5章 金利モデルのキャリブレーション

ボラティリティ・スマイル、Hull–White、BGMへの接続

第II-5章 金利モデルのキャリブレーション

金利モデルを決めるとき、最初に市場から得られるのはモデルのパラメータではない。割引カーブ、キャップやスワップションの価格、そこから逆算されたボラティリティである。モデルのパラメータを選び、これらの市場価格を再現する作業をキャリブレーションという。

前章までに、割引カーブとBlack型のオプション評価を扱った。本章では、まずNormal型を含めて市場クォートの単位をそろえ、SABRのスマイルに適合させる。次にHull–Whiteの平均回帰速度と短期金利ボラティリティを、オプション価格から推定する。最後にBGM（Brace–Gatarek–Musiela）モデルのキャリブレーションで必要になるフォワード金利間の相関を考える。

同じ「市場への適合」でも、何に合わせるかによって、パラメータが表すものは異なる。SABRは主に行使金利方向のスマイル、Hull–Whiteは満期・原資産年限方向の金利変動、BGMは複数フォワード金利のボラティリティと共変動を記述する。これらをひとまとめの最小二乗問題として扱う前に、各市場クォートの意味を確定する必要がある。

  if (requireNamespace("GaussQuant", quietly = TRUE)) {

  } else {

  }

II-5.1 市場価格からモデルパラメータへ

II-5.1.1 評価の入力を分ける

以下の四つを区別する。

入力 例 キャリブレーションにおける役割
契約条件 行使日、金利期間、行使金利、想定元本 評価対象を定義する
割引・予測カーブ OIS割引係数、期間別フォワード金利 評価の基準となる市場状態
オプション市場 Caplet、Cap、Swaptionの価格またはボラティリティ パラメータを合わせる対象
モデル SABRの \(\alpha,\beta,\nu,\rho\)、Hull–Whiteの \(a,\sigma\) 推定するパラメータ

現代のマルチカーブ評価では、フォワード金利を作るカーブと割引カーブが同じとは限らない。市場ボラティリティだけを移して、カーブや日数計算規則を変えれば、同じモデルパラメータでも価格は変わる。以下の数値例では、各例のカーブと市場クォートを明示する。

II-5.1.2 目的関数と再評価

市場商品の価格を \(V_i^{\mathrm{mkt}}\)、パラメータ \(\boldsymbol\theta\) で評価した価格を \(V_i(\boldsymbol\theta)\) とする。たとえば重み付き価格誤差を

\[ J(\boldsymbol\theta) = \sum_{i=1}^{n}w_i \left[V_i(\boldsymbol\theta)-V_i^{\mathrm{mkt}}\right]^2 \]

として最小化する。市場ボラティリティへ直接適合させる場合は、価格の代わりに同じ定義・単位のボラティリティを用いる。

重み \(w_i\) の選び方によって、価格の大きな商品が結果を支配するか、相対的な誤差をそろえるかが変わる。最適化関数が終了したことと、市場を十分に再現したことは別である。適合後は、パラメータの範囲、市場クォートごとの残差、未使用商品の再評価を確認する。

II-5.2 BlackとNormalのボラティリティ

II-5.2.1 同じ単位の数値を比べない

Blackのボラティリティ \(\sigma_B\) は金利の相対的な変化を表し、Normalのボラティリティ \(\sigma_N\) は金利と同じ絶対変化の単位を持つ。例えばBlack 40%は 0.40、Normal 40bpは 0.0040 であり、数値が違っても両方とも同じ商品の市場価格を表し得る。

欧州型オプションの符号を \(\omega=1\)（コール）または \(-1\)（プット）、フォワードを \(F\)、行使金利を \(K\)、行使までの年数を \(T\)、割引と想定元本等をまとめた正の係数を \(D\) とする。Normal型の価格は

\[ V_N=D\left[\omega(F-K)N(\omega d)+ \sigma_N\sqrt{T}\,\phi(d)\right], \qquad d=\frac{F-K}{\sigma_N\sqrt{T}} \]

である。\(F\) や \(K\) が負でも定義できる。Black型は正の \(F,K\) を必要とし、負金利を含む場合にはNormal型または共通のシフトを加えるShifted Black型が候補となる。

normal_option_price_LRL <- function(
  forward,
  strike,
  volatility,
  maturity,
  discount_factor = 1,
  option_sign = 1
) {
  intrinsic <- discount_factor * max(
    option_sign * (forward - strike), 0
  )
  standard_deviation <- volatility * sqrt(maturity)

  if (standard_deviation == 0) return(intrinsic)

  d <- (forward - strike) / standard_deviation
  discount_factor * (
    option_sign * (forward - strike) *
      stats::pnorm(option_sign * d) +
      standard_deviation * stats::dnorm(d)
  )
}

II-5.3 SABRによるスマイルのキャリブレーション

II-5.3.1 パラメータと市場データ

SABRは、フォワード \(F_t\) とそのボラティリティ水準 \(\alpha_t\) を確率変数として扱う。実務で利用する近似インプライド・ボラティリティは、概念的に

\[ \sigma_{\mathrm{impl}}(K) = g(F_0,K,T;\alpha,\beta,\nu,\rho) \]

である。\(\alpha\) は主にATM付近の水準、\(\beta\) は金利水準に対する拡散係数の依存、\(\nu\) はボラティリティの変動、\(\rho\) はスマイルの傾きに関係する。ただし互いに独立ではなく、一組の市場データだけで四つを安定して推定できるとは限らない。以下は \(\beta=0.5\) を固定して残り三つを推定する。

II-5.3.2 目的関数と制約

市場Blackボラティリティと、同じ定義のSABR近似値との二乗誤差を最小化する。\(\alpha>0\)、\(\nu\geq0\)、\(-1<\rho<1\) とし、評価関数が非有限値を返す候補は棄却する。近似式の計算には既存のGaussQuant関数を利用する。

compute_sabr_black_volatility_LRL <- function(
  strike,
  parameters
) {
  GaussQuant::safe_sabr_vol_GQL(
    strike = strike,
    forward = sabr_forward,
    maturity = sabr_maturity,

}

sabr_objective_LRL <- function(parameters) {
  names(parameters) <- c("alpha", "volvol", "rho")

  model_vol <- tryCatch(
    purrr::map_dbl(
      tbl_sabr_market$strike,
      \(strike) compute_sabr_black_volatility_LRL(
        strike, parameters
      )
    ),
    error = \(e) rep(NA_real_, nrow(tbl_sabr_market))
  )

  if (any(!is.finite(model_vol))) return(1e6)

  mean((model_vol - tbl_sabr_market$black_volatility)^2)
}

II-5.3.3 負金利とモデル選択

負の行使金利を含む場合、通常の対数正規SABRのBlack近似にそのまま代入できない。市場がNormalボラティリティでクォートされているなら、Normal型の近似式とその単位に合わせて目的関数を作る。Shifted SABRを使う場合には、すべての評価対象について \(F+s>0\)、\(K+s>0\) を満たすシフト \(s\) を選び、その値をクォートの仕様として記録する。

現行の第6章にあった負金利の例は、この原則を確認する発展例として残す。Blackのボラティリティ残差とNormalのボラティリティ残差を、数値の大小だけで比較してはならない。

II-5.4 Hull–Whiteのパラメータ推定

II-5.4.1 二つのパラメータの役割

Hull–White 1因子モデルは

\[ dr_t=\{\theta(t)-a r_t\}dt+\sigma dW_t \]

と書ける。\(\theta(t)\) は初期割引カーブとの整合を担い、\(a\) は平均回帰速度、\(\sigma\) は短期金利の拡散係数を表す。初期カーブを再現することと、オプション市場へ \(a,\sigma\) を合わせることは異なる工程である。動学と初期カーブの再現条件は次章で導く。

現行の第7章には、1Y×5Y ATMスワップションのNormalボラティリティ36.06bpを一つのHelperとして、\(a=0.03\) を固定して \(\sigma\) のみを最適化する例がある。市場点一つから二つのパラメータを同時に安定推定できないため、ここではまず解析式で検算できるゼロクーポン債オプションで二つのパラメータと識別性を見る。その後でスワップション市場への拡張を説明する。

II-5.4.2 債券オプションの解析価格

説明用に初期ゼロ金利 \(r_0\) が一定とし、オプション満期を \(T\)、原資産のゼロクーポン債満期を \(S>T\) とする。\(P(0,t)=e^{-r_0t}\)、行使価格を \(K\) とするコールの価格は、

\[ C=P(0,S)N(h)-KP(0,T)N(h-v), \qquad h=\frac{\log[P(0,S)/(KP(0,T))]}{v}+\frac{v}{2}, \]

\[ v=\frac{\sigma}{a}(1-e^{-a(S-T)}) \sqrt{\frac{1-e^{-2aT}}{2a}} \]

で求められる。\(v\) はオプション満期までに蓄積される債券価格の標準偏差である。次の関数は \(a>0,\sigma>0\) の範囲で計算する。

compute_hw_bond_option_price_LRL <- function(
  option_maturity,
  bond_maturity,
  strike,
  mean_reversion,
  short_rate_volatility,
  initial_zero_rate
) {
  stopifnot(
    option_maturity > 0,
    bond_maturity > option_maturity,
    strike > 0,
    mean_reversion > 0,
    short_rate_volatility > 0
  )

  discount_option <- exp(-initial_zero_rate * option_maturity)
  discount_bond <- exp(-initial_zero_rate * bond_maturity)

  bond_std_dev <- short_rate_volatility /
    mean_reversion *
    (-expm1(-mean_reversion *
      (bond_maturity - option_maturity))) *
    sqrt(
      -expm1(-2 * mean_reversion * option_maturity) /
        (2 * mean_reversion)
    )

  h <- log(
    discount_bond / (strike * discount_option)
  ) / bond_std_dev + bond_std_dev / 2

  discount_bond * stats::pnorm(h) -
    strike * discount_option *
      stats::pnorm(h - bond_std_dev)
}

II-5.5 BGMモデルとBrigo–Mercurioへの接続

II-5.5.1 キャップレットだけでは相関が決まらない

BGMは、単一の短期金利ではなく、各期間のフォワード金利 \(L_i(t)\) をまとめて確率的に扱う市場モデルである。各満期のCapletから個別のボラティリティについて情報を得られる一方、複数のフォワード金利にまたがるSwaptionは、金利間の相関にも依存する。

Brigo–Mercurioは独立した一つのモデル名ではなく、金利モデルの理論と市場適合、とりわけLIBOR市場モデルのボラティリティと相関の校正を体系化した文献を指す。本節ではBGMの完全なシミュレーションを作らず、キャリブレーションでどの情報が不足するかを可視化する。

フォワード金利の変動係数を \(\sigma_i\)、共通の評価時間を \(T\) とする。スワップレートを局所的に固定ウェイト \(w_i\) の和で近似すると、その分散率の近似は

\[ \sigma_S^2 \approx \sum_{i,j}w_iw_j\sigma_i\sigma_j\rho_{ij}. \]

これは説明用の固定ウェイト近似であり、BGMにおける測度変換・ドリフト・ボラティリティの期間依存や真のスワップション価格を実装した式ではない。

II-5.5.2 説明用の相関適合

\(\rho_{ij}=\exp[-\kappa|T_i-T_j|]\) と置くと、同じ個別ボラティリティでも \(\kappa\) によってスワップレートの分散が変わる。ここでも合成クォートを使い、相関パラメータだけを逆算する。

compute_bgm_swap_vol_proxy_LRL <- function(
  correlation_decay,
  tenor,
  caplet_volatility,
  weights
) {
  correlation <- exp(
    -correlation_decay *
      abs(outer(tenor, tenor, "-"))
  )
  weighted_volatility <- weights * caplet_volatility
  sqrt(as.numeric(
    t(weighted_volatility) %*%
      correlation %*% weighted_volatility
  ))
}

bgm_tenor <- 1:4
bgm_caplet_vol <- c(0.24, 0.22, 0.21, 0.20)
bgm_weights <- c(0.28, 0.26, 0.24, 0.22)
bgm_reference_decay <- 0.45

bgm_swaption_vol_proxy <-
  compute_bgm_swap_vol_proxy_LRL(
    correlation_decay = bgm_reference_decay,
    tenor = bgm_tenor,
    caplet_volatility = bgm_caplet_vol,
    weights = bgm_weights
  )

bgm_fit <- stats::optimize(
  f = \(correlation_decay) {
    (
      compute_bgm_swap_vol_proxy_LRL(
        correlation_decay = correlation_decay,
        tenor = bgm_tenor,
        caplet_volatility = bgm_caplet_vol,
        weights = bgm_weights
      ) - bgm_swaption_vol_proxy
    )^2
  },
  interval = c(0.01, 2)
)

実際のBGM校正では、CapletとSwaptionの市場データ、必要なら複数行使価格のスマイルを同時に考える。相関行列が正定値となるパラメータ化、ボラティリティの満期構造、カーブとの整合、近似評価とMonte Carlo評価との差を検証する。SABRに合わせた各行使金利のスマイルが、自動的にBGMの全期間・全商品へ整合するわけではない。モデル動学と評価測度は次章で扱う。

確認項目 SABR Hull–White BGM

最適化の成功だけでモデル採用を決めない。入力の単位、目的関数、パラメータの識別性、市場クォートごとの残差、未使用商品の価格を合わせて確認する。モデルが市場価格に合っていても、早期償還商品の将来金利シナリオや行使境界が適切とは限らない。

II-5.7 まとめと次章への接続

本章では、金利モデルの校正を「市場クォートを読む」「価格またはボラティリティの評価式を定める」「制約付きで推定する」「市場点と未使用商品を再評価する」という順序で整理した。Normalモデルを独立した商品別の説明として展開する代わりに、市場ボラティリティの定義と負金利への対応として位置づけた。SABRのスマイル、Hull–Whiteのオプション市場、BGMの複数フォワード金利と相関では、校正対象がそれぞれ異なる。

第II-6章では、Hull–Whiteの短期金利とBGMを含むフォワードレートモデルの時間発展を学ぶ。第II-7章では、そこで得た金利シナリオを使い、Callable BondやBermudan Swaptionの早期行使を評価する。
