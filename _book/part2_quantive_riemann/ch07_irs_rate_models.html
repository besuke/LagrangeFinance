第II-7章 ショートレートモデルとフォワード金利モデル

第6章では市場のオプション価格を使ってモデルのパラメータを決めた。本章では、そのパラメータを受け取ったモデルが何を状態変数として動かし、どのように金利の将来経路を作るかを考える。第8章の早期償還評価では、各行使時点の継続価値を、これらの金利経路のもとで比べる。

短期金利を直接動かすHull–White、瞬間フォワード金利の曲線全体を動かすHJM、決められた期間のフォワード金利を動かすBGM/LMMでは、同じスワップションに合わせていても状態変数と計算方法が違う。さらに翌日物金利を期間中に積み上げる後決め複利は、従来の期間開始時に確定するLIBORと区別しなければならない。

以下の数値は仕組みを確認するための架空の入力である。第6章の説明用キャリブレーション結果でも、実取引の評価でもない。

II-7.1 短期金利とフォワード金利

時点 \(t\) の満期 \(T\) のゼロクーポン債価格を \(P(t,T)\) とする。割引曲線が十分なめらかなら、瞬間フォワード金利は \(f(t,T)=-\partial_T\log P(t,T)\)、短期金利は \(r_t=f(t,t)\) である。単一曲線の設定に限り、\([T_i,T_{i+1}]\) の単利フォワード金利は

\[L_i(t)=\frac{1}{\Delta_i} \left(\frac{P(t,T_i)}{P(t,T_{i+1})}-1\right), \qquad \Delta_i=\operatorname{yearfrac}(T_i,T_{i+1}),\quad t\leq T_i.\]

枠組み 主に動かす量 自然な用途 注意点
Hull–White 1因子 短期金利 \(r_t\) 割引、債券オプション、行使判断 単一因子では曲線変動の形に制約がある
HJM 瞬間フォワード曲線 \(f(t,T)\) 曲線全体の整合的な記述 ボラティリティに応じたドリフト制約が必要
BGM/LMM 期間別フォワード \(L_i(t)\) Caplet、Swaptionと複数金利の共変動 古典的な定義は期間開始時に確定するフォワード金利を想定する
RFR向けFMM 後決め複利金利に対応する市場フォワード 翌日物金利の複利支払を含む契約 金利期間中の確定済み部分と未確定部分を分ける

実務の複数曲線設定では、OISの割引係数と予測対象の期間金利を同一の \(P(t,T)\) から機械的に作らない。以降、単一曲線を仮定する数式にはその旨を明示する。

II-7.2 短期金利：VasicekからHull–Whiteへ

定数の長期水準 \(b\) に回帰するVasicekモデルは

\[dr_t=a(b-r_t)\,dt+\sigma\,dW_t,\qquad a>0\]

と書ける。Hull–White 1因子モデルではドリフトを時間依存にして

\[dr_t=[\theta(t)-ar_t]dt+\sigma\,dW_t\]

とし、所与の初期割引曲線 \(P(0,T)\) を再現する。\(a\) は年率の平均回帰速度、\(\sigma\) は短期金利の絶対変動の年率パラメータである。Gaussianモデルなので、短期金利が負になる確率もある。

計算には \(r_t=\phi(t)+x_t\) と分解すると便利である。\(x_0=0\) として

\[dx_t=-ax_t\,dt+\sigma\,dW_t.\]

一定の \(a,\sigma\) と十分なめらかさを仮定したとき、初期瞬間フォワード \(f(0,t)\) に対応する決定論的な項は

\[\phi(t)=f(0,t)+\frac{\sigma^2}{2a^2}(1-e^{-at})^2.\]

したがって初期曲線が \(P(0,T)=e^{-r_0T}\) のフラットな連続複利曲線なら、上式の \(f(0,t)\) は \(r_0\) になる。後のコードではこのフラット曲線だけを使う。

刻み \(h\) におけるOU状態の厳密な条件付き遷移は

\[x_{t+h}=e^{-ah}x_t+ \sigma\sqrt{\frac{1-e^{-2ah}}{2a}}\,Z, \qquad Z\sim N(0,1).\]

これは状態の遷移に関して厳密である。一方、割引係数 \(\exp(-\int_0^T r_s ds)\) を左端の値による和で近似すると、時間離散化誤差は残る。

compute_hw_shift_LRL <- function(time, flat_rate, mean_reversion, volatility) {
  stopifnot(mean_reversion > 0, volatility >= 0, all(time >= 0))
  flat_rate + volatility^2 / (2 * mean_reversion^2) *
    (1 - exp(-mean_reversion * time))^2
}

simulate_hw_paths_LRL <- function(
  flat_rate, mean_reversion, volatility,
  horizon = 5, steps_per_year = 24L, number_of_paths = 8000L,
  seed = 617L
) {
  stopifnot(
    mean_reversion > 0, volatility >= 0,
    horizon > 0, steps_per_year > 0, number_of_paths > 1
  )
  number_of_steps <- as.integer(horizon * steps_per_year)
  stopifnot(abs(number_of_steps / steps_per_year - horizon) < 1e-10)
  step_size <- horizon / number_of_steps
  times <- seq(0, horizon, length.out = number_of_steps + 1L)
  set.seed(seed)
  shocks <- matrix(
    stats::rnorm(number_of_paths * number_of_steps),
    nrow = number_of_paths
  )
  decay <- exp(-mean_reversion * step_size)
  shock_scale <- volatility * sqrt(
    -expm1(-2 * mean_reversion * step_size) / (2 * mean_reversion)
  )
  states <- do.call(
    cbind,
    purrr::accumulate(
      seq_len(number_of_steps),
      .init = rep(0, number_of_paths),
      .f = function(previous, index) {
        decay * previous + shock_scale * shocks[, index]
      }
    )
  )
  rates <- sweep(
    states, 2,
    compute_hw_shift_LRL(times, flat_rate, mean_reversion, volatility),
    FUN = "+"
  )
  list(times = times, rates = rates, step_size = step_size)
}

  flat_rate = 0.02, mean_reversion = 0.12, volatility = 0.01
)

compute_hw_discount_check_LRL <- function(simulation, flat_rate, maturities) {
  step_size <- simulation$step_size
  maturity_steps <- as.integer(round(maturities / step_size))
  stopifnot(
    all(maturity_steps > 0),
    all(maturity_steps < ncol(simulation$rates)),
    all(abs(maturity_steps * step_size - maturities) < 1e-10)
  )
  discount_matrix <- exp(-t(apply(
    simulation$rates[, -ncol(simulation$rates), drop = FALSE] * step_size,
    1, cumsum
  )))
  purrr::map_dfr(seq_along(maturities), function(index) {
    discounts <- discount_matrix[, maturity_steps[index]]
    tibble::tibble(
      maturity = maturities[index],
      initial_curve = exp(-flat_rate * maturities[index]),
      simulation = mean(discounts),
      mc_standard_error = stats::sd(discounts) / sqrt(length(discounts))
    )
  }) |>
    dplyr::mutate(difference = simulation - initial_curve)
}

II-7.3 HJM：瞬間フォワードモデル

HJMでは満期 \(T\) ごとの \(f(t,T)\) に対し、リスク中立測度と短期金利によるマネーマーケット口座を基準に

\[df(t,T)=\alpha(t,T)\,dt+ \sum_{k=1}^{m}\sigma_k(t,T)\,dW_{k,t}\]

と置く。無裁定の条件は、通常の連続モデルの仮定のもとで

\[\alpha(t,T)=\sum_{k=1}^{m}\sigma_k(t,T) \int_t^T\sigma_k(t,u)\,du\]

である。ボラティリティ曲面を指定すれば、ドリフトは自由な調整項ではない。\(P(t,T)=\exp(-\int_t^T f(t,u)du)\) から債券価格が定まる。

Hull–White 1因子は、例えば満期方向のボラティリティを \(\sigma_f(t,T)=\sigma e^{-a(T-t)}\) とするGaussian HJMの特別な場合として見られる。満期が長いほど短期のショックの効果が小さくなる。その形を図で確認する。

tbl_hjm_loading <- tibble::tibble(
  time_to_maturity = seq(0, 15, by = 0.1)
) |>
  dplyr::mutate(
    forward_volatility = 0.01 * exp(-0.12 * time_to_maturity)
  )

ggplot2::ggplot(

  ggplot2::geom_line(colour = "#286DA8", linewidth = 0.9) +

HJMは連続した満期の曲線を出発点とし、瞬間フォワードのボラティリティから無裁定のドリフトを定める。ただし、そのボラティリティ曲面を直接クォートする市場はないため、CapletやSwaptionの観測価格に合わせるモデル化が必要になる。次のBGM/LMMは、実際の金利期間に対応するフォワードを状態変数として扱う。上のドリフト式のとおり、HJMの瞬間フォワード金利は一般にマルチンゲールではない。

II-7.4 BGM/LMM：期間別フォワード

BGM（Brace–Gatarek–Musiela）/LMM（LIBOR Market Model）では、\(L_i(t)\) ごとにボラティリティと金利間の相関を指定する。単一曲線の \(T_{i+1}\) フォワード測度では、正の \(L_i\) を仮定する古典的な対数正規モデルを

\[\frac{dL_i(t)}{L_i(t)} =\boldsymbol\sigma_i(t)\cdot d\boldsymbol W_t^{T_{i+1}}, \qquad 0\leq t\leq T_i\]

と書ける。この測度では当該期間の \(L_i\) はマルチンゲールである。一方、すべての期間金利を同じ測度で同時に動かすなら測度変換によるドリフトが必要である。フォワードごとに上式の無ドリフト遷移を並べるだけでは、一般に完全な共同シミュレーションにならない。

古典的な対数正規モデルは正のフォワードを前提とする。負の金利を許すNormal型やShifted Lognormal型を採用する場合は、ダイナミクスと市場ボラティリティの定義を合わせる。マルチカーブではOIS割引曲線と予測フォワードを分け、上の単一曲線の債券比率をそのままIBOR予測に流用しない。

満期 \(T_i\) までのボラティリティが一定の例では、当該フォワード測度の周辺分布は

\[L_i(T_i)=L_i(0)\exp\left[-\tfrac12\nu_i^2T_i+ \nu_i\sqrt{T_i}\,Z\right].\]

この分布から求めたCapletのシミュレーション価格をBlack公式と比較する。価格係数は \(N\Delta_iP(0,T_{i+1})\) とし、\(N\) を想定元本とする。この例は一つのCapletの周辺分布の検証であり、BGM全体の共同経路ではない。

compute_black_caplet_LRL <- function(
  forward, strike, volatility, expiry,
  accrual, discount_factor, notional = 1
) {
  stopifnot(
    forward > 0, strike > 0, volatility >= 0, expiry >= 0,
    accrual > 0, discount_factor > 0, notional > 0
  )
  scale <- notional * accrual * discount_factor
  total_volatility <- volatility * sqrt(expiry)
  if (total_volatility == 0) {
    return(scale * max(forward - strike, 0))
  }
  d1 <- (log(forward / strike) + total_volatility^2 / 2) /
    total_volatility
  d2 <- d1 - total_volatility
  scale * (
    forward * stats::pnorm(d1) - strike * stats::pnorm(d2)
  )
}

forward_0 <- 0.025
strike <- 0.0275
expiry <- 2
volatility <- 0.24
accrual <- 0.5

    volatility * sqrt(expiry) * stats::rnorm(number_of_paths)

II-7.5 後決め金利とFMMモデル

伝統的なLIBOR連動期間金利は、通常、金利期間の開始前または開始時に、その期間に適用するレートが観測される。TONARなどの翌日物RFRを日々複利で積み上げる契約では、期間 \([T_i,T_{i+1}]\) の利息の大部分は期間開始時にまだ確定していない。

期間内の各日の翌日物金利を \(R_j\)、対応する日数割合を \(\delta_j\)、全期間の日数割合を \(\Delta_i\) とすれば、観測済みの期間複利金利は概念上

\[R_i^{\mathrm{comp}}= \frac{\displaystyle\prod_{j\in[T_i,T_{i+1})} (1+\delta_jR_j)-1}{\Delta_i}.\]

実際の契約では休日、観測日と適用日のずれ、lookbackやlockoutなどの規則が効くため、日程と日数割合を契約に従って作る。この式だけで実際のTONARの支払額を定義したことにはならない。

compute_compounded_overnight_LRL <- function(
  overnight_rates, day_fractions, period_fraction = sum(day_fractions)
) {
  stopifnot(
    length(overnight_rates) == length(day_fractions),
    length(overnight_rates) > 0,
    all(is.finite(overnight_rates)),
    all(is.finite(day_fractions)),
    all(day_fractions > 0), period_fraction > 0,
    all(1 + day_fractions * overnight_rates > 0)
  )
  (prod(1 + day_fractions * overnight_rates) - 1) /
    period_fraction
}

tbl_daily_fixings <- tibble::tibble(
  observation = seq_len(90),
  day_fraction = 1 / 365,
  overnight_rate = 0.01 + 0.004 *
    sin(2 * pi * observation / 90)
) |>
  dplyr::mutate(
    realized_factor = cumprod(1 + day_fraction * overnight_rate),
    fraction_elapsed = cumsum(day_fraction),
    realized_rate_to_date = (realized_factor - 1) /
      fraction_elapsed
  )

tbl_compound_summary <- tibble::tibble(
  observations = nrow(tbl_daily_fixings),
