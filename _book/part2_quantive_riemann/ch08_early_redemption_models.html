第II-8章 金利モデルによる早期償還評価

固定利付債の発行体に期限前償還権があると、金利が低下した際に、高いクーポンの支払いを打ち切って借り換えることができる。第6章でモデルのパラメータを市場に合わせ、第7章で金利の動きを定義した。本章では、そのモデルを使い、各行使日にどの価値を比較して債券価格が決まるかを計算する。

まず発行体が指定日に額面で償還できる固定利付債（Callable Bond）をHull–White 1因子モデルで評価する。次にMBSのプリペイメントをモデル化する。発行体のコールと住宅ローン債務者の繰上返済は、どちらも元本の早期返済だが、行動主体とキャッシュフローが異なる。以下の金利、クーポン、ボラティリティはすべて教材用の架空の値である。

II-8.1 発行体条件と債券評価

額面100、年率3%の固定クーポン、半年払い、満期5年の債券を考える。各クーポンは Ｊは\(100\times0.03\times0.5=1.5\)。発行体は1年目から4年半目までの各クーポン日に、その日のクーポンを支払った後、残りの元本を100で償還できるとする。満期日には通常の元本償還があり、コール判断はない。

II-8.2 満期債と発行体コール

コールオプションないBullet Bondの時点0の価格は、支払額を \(C_i\)、満期元本を \(N\)、割引係数を \(P(0,t_i)\) として

\[V_0^{\mathrm{bullet}} =\sum_{i=1}^{n} C_i P(0,t_i)+N P(0,t_n).\]

初期カーブを完全に再現するモデルなら、同じキャッシュフローから得るBullet Bondの価格はこの値に一致する。コール価格や行使日などの条件が一致すれば、発行体のコールオプション価値は

\[V_0^{\mathrm{issuer\ call}} =V_0^{\mathrm{bullet}}-V_0^{\mathrm{callable}}\geq0\]

となる。これは同一の信用・割引・クーポン条件で比較した価格差であり、別に提示された任意のReceiver Swaption価格と自動的に一致するわけではない。

compute_bullet_price_LRL <- function(tbl_cashflows, flat_rate) {
  stopifnot(is.finite(flat_rate))
  sum(
    (tbl_cashflows$coupon + tbl_cashflows$principal_at_maturity) *
      exp(-flat_rate * tbl_cashflows$payment_time)
  )
}

bullet_curve_price <- compute_bullet_price_LRL(
  tbl_cashflows, flat_zero_rate
)
show_early_redemption_tbl_LRL(
  tibble::tibble(bullet_price = bullet_curve_price),
  "初期割引曲線によるBullet Bondの価格"
)

II-8.3 発行体の行使判断とバックワード・インダクション

クーポン支払日の直後に、将来の支払義務の価値を発行体が比較する。その時点から次の支払日までの継続価値を \(H_i(x)\)、コール時に支払う元本を \(K_i\)、当日のクーポンを \(C_i\) とする。直前の投資家側の価格は

\[V_i(x)=C_i+\min\{K_i,H_i(x)\} \quad (\text{発行体がコール可能な日}),\]

であり、コール不可の日は \(V_i(x)=C_i+H_i(x)\)、満期では \(V_n(x)=C_n+N\)。クーポン \(C_i\) はコール時にも支払われるため、比較する二つの枝の共通部分として外に置いた。

継続価値は、リスク中立測度のもとで

\[H_i(x)=\mathbb E^{\mathbb Q}\!\left[ \exp\left(-\int_{t_i}^{t_{i+1}}r_s\,ds\right) V_{i+1}(x_{t_{i+1}})\mid x_{t_i}=x\right].\]

発行体は \(H_i(x)>K_i\) のときコールする。等号のときの扱いは価格を変えない。\(\min\) が表すのは、発行体が投資家に対する残存債務をより安く決済できる枝を選ぶことである。

flowchart TD
  A["当日のクーポンを支払う"] --> B["元本のコール価格と継続価値を比較"]
  B -->|"継続価値が高い"| C["元本を支払い償還"]
  B -->|"継続価値が低い"| D["債券を継続"]

II-8.4 Hull–Whiteモデル

II-8.4.1 状態と割引の共同分布

第7章と同じく、\(r_t=\phi(t)+x_t\)、\(dx_t=-a x_tdt+\sigma dW_t\) を使う。一定の \(a>0,\sigma\geq0\) とフラットな初期曲線 \(P(0,T)=e^{-\bar rT}\) について

\[\phi(t)=\bar r+ \frac{\sigma^2}{2a^2}(1-e^{-at})^2.\]

\(h=t_{i+1}-t_i\)、\(b=e^{-ah}\)、\(B=(1-b)/a\) と置く。時点 \(t_i\) の \(x\) を条件とした次の状態 \(X\) と期間内の確率的な割引用積分 \(I\) は

\[X=bx+\varepsilon_X,\qquad I=\int_{t_i}^{t_{i+1}}x_sds=Bx+\varepsilon_I,\]

であり、誤差の組は平均0の二変量正規分布になる。その分散・共分散を

\[\begin{aligned} v_X&=\frac{\sigma^2(1-b^2)}{2a},\\ v_I&=\frac{\sigma^2}{a^2} \left[h-\frac{2(1-b)}{a}+\frac{1-b^2}{2a}\right],\\ c_{XI}&=\frac{\sigma^2(1-b)^2}{2a^2} \end{aligned}\]

と書く。積分を単に \(h r_{t_i}\) とする近似を避けるため、\(X\) の値に条件づけた \(I\) の正規分布を用いる。\(v_X>0\) の場合、標準正規 \(Z\) に対し

\[\begin{aligned} H_i(x)=&\exp\left[-\int_{t_i}^{t_{i+1}}\phi(s)ds -Bx+\tfrac12\left(v_I-\frac{c_{XI}^2}{v_X}\right)\right]\\ &\times\mathbb E_Z\left[ e^{-(c_{XI}/\sqrt{v_X})Z} V_{i+1}(bx+\sqrt{v_X}Z)\right]. \end{aligned}\]

この1次元の期待値を正規分布用のGauss–Hermite求積で計算し、次時点の状態ごとの価格を線形補間する。状態の格子幅と両端、および求積点数による数値誤差が残る。\(\sigma=0\) のときは決定論的な遷移に切り替える。

compute_normal_quadrature_LRL <- function(number_of_nodes = 24L) {
  stopifnot(number_of_nodes >= 2)
  number_of_nodes <- as.integer(number_of_nodes)
  off_diagonal <- sqrt(seq_len(number_of_nodes - 1L))
  jacobi <- matrix(0, number_of_nodes, number_of_nodes)
  jacobi[cbind(
    seq_len(number_of_nodes - 1L),
    seq_len(number_of_nodes - 1L) + 1L
  )] <- off_diagonal
  jacobi[cbind(
    seq_len(number_of_nodes - 1L) + 1L,
    seq_len(number_of_nodes - 1L)
  )] <- off_diagonal
  roots <- eigen(jacobi, symmetric = TRUE)
  list(nodes = roots$values, weights = roots$vectors[1, ]^2)
}

compute_hw_shift_integral_LRL <- function(
  start_time, end_time, flat_rate, mean_reversion, volatility
) {
  a <- mean_reversion
  h <- end_time - start_time
  flat_rate * h + volatility^2 / (2 * a^2) * (
    h - 2 * (exp(-a * start_time) - exp(-a * end_time)) / a +
      (exp(-2 * a * start_time) - exp(-2 * a * end_time)) /
        (2 * a)
  )
}

compute_discounted_step_LRL <- function(
  next_values, state_grid, current_states,
  start_time, end_time, flat_rate,
  mean_reversion, volatility, quadrature
) {
  a <- mean_reversion
  h <- end_time - start_time
  b <- exp(-a * h)
  B <- -expm1(-a * h) / a
  deterministic_integral <- compute_hw_shift_integral_LRL(
    start_time, end_time, flat_rate, a, volatility
  )
  if (volatility == 0) {
    return(
      exp(-deterministic_integral - B * current_states) *
        stats::approx(
          state_grid, next_values, xout = b * current_states,
          rule = 2
        )$y
    )
  }

  variance_next <- volatility^2 * (-expm1(-2 * a * h)) / (2 * a)
  variance_integral <- volatility^2 / a^2 * (
    h - 2 * B + (-expm1(-2 * a * h)) / (2 * a)
  )
  covariance <- volatility^2 * (-expm1(-a * h))^2 /
    (2 * a^2)
  residual_variance <- max(
    variance_integral - covariance^2 / variance_next, 0
  )
  standard_deviation_next <- sqrt(variance_next)

  next_states <- outer(
    current_states, quadrature$nodes,
    function(state, shock) b * state + standard_deviation_next * shock
  )
  interpolated_values <- matrix(
    stats::approx(
      state_grid, next_values, xout = as.vector(next_states),
      rule = 2
    )$y,
    nrow = length(current_states)
  )
  conditional_weights <- quadrature$weights * exp(
    -covariance / standard_deviation_next * quadrature$nodes
  )
  as.vector(
    exp(-deterministic_integral - B * current_states +
      residual_variance / 2) *
      (interpolated_values %*% conditional_weights)
  )
}

II-8.4.2 行使日ごとのバックワード・インダクション

満期にクーポンと元本を置き、一つ前の支払日に条件付き割引期待値を求める。以後、コール可能日では \(\min\) を取ってさかのぼる。比較のため、まったく同じ状態格子と割引演算子でBullet Bondも評価する。

compute_callable_bond_LRL <- function(
  tbl_cashflows, flat_rate, mean_reversion, volatility,
  number_of_grid_points = 321L,
  grid_limit = 0.13, quadrature_nodes = 24L
) {
  stopifnot(
    nrow(tbl_cashflows) >= 2, mean_reversion > 0,
    volatility >= 0, number_of_grid_points >= 3,
    grid_limit > 0, quadrature_nodes >= 2,
    all(diff(tbl_cashflows$payment_time) > 0),
    all(tbl_cashflows$coupon >= 0),
    all(tbl_cashflows$principal_at_maturity[
      -nrow(tbl_cashflows)
    ] == 0),
    all(!is.na(tbl_cashflows$call_principal[
      tbl_cashflows$issuer_can_call
    ]))
  )
  grid <- seq(-grid_limit, grid_limit,
    length.out = number_of_grid_points
  )
  quadrature <- compute_normal_quadrature_LRL(quadrature_nodes)
  number_of_periods <- nrow(tbl_cashflows)
  maturity_value <- rep(
    tbl_cashflows$coupon[number_of_periods] +
      tbl_cashflows$principal_at_maturity[number_of_periods],
    length(grid)
  )
  terminal <- list(
    bullet = maturity_value,
    callable = maturity_value,
    decisions = list()
  )
  history <- purrr::accumulate(
    rev(seq_len(number_of_periods - 1L)),
    .init = terminal,
    .f = function(next_state, payment_index) {
      start_time <- tbl_cashflows$payment_time[payment_index]
      end_time <- tbl_cashflows$payment_time[payment_index + 1L]
      price_step <- function(next_values) {
        compute_discounted_step_LRL(
          next_values, grid, grid,
          start_time, end_time, flat_rate,
          mean_reversion, volatility, quadrature
        )
      }
      bullet_continuation <- price_step(next_state$bullet)
      callable_continuation <- price_step(next_state$callable)
      can_call <- tbl_cashflows$issuer_can_call[payment_index]
      call_amount <- tbl_cashflows$call_principal[payment_index]
      exercise_now <- if (can_call) {
        callable_continuation > call_amount
      } else {
        rep(FALSE, length(grid))
      }
      investor_value <- if (can_call) {
        pmin(call_amount, callable_continuation)
      } else {
        callable_continuation
      }
      decision <- if (can_call) {
        list(tibble::tibble(
          payment_time = start_time,
          state = grid,
          short_rate = flat_rate +
            volatility^2 / (2 * mean_reversion^2) *
              (1 - exp(-mean_reversion * start_time))^2 + grid,
          continuation_ex_coupon = callable_continuation,
          call_principal = call_amount,
          exercise_now = exercise_now
        ))
      } else {
        list()
      }
      list(
        bullet = tbl_cashflows$coupon[payment_index] +
          bullet_continuation,
        callable = tbl_cashflows$coupon[payment_index] +
          investor_value,
        decisions = c(decision, next_state$decisions)
      )
    }
  )
  first_period <- history[[length(history)]]
  price_at_zero <- function(next_values) {
    compute_discounted_step_LRL(
      next_values, grid, current_states = 0,
      start_time = 0,
      end_time = tbl_cashflows$payment_time[1],
      flat_rate = flat_rate,
      mean_reversion = mean_reversion,
      volatility = volatility,
      quadrature = quadrature
    )
  }
  bullet_price <- price_at_zero(first_period$bullet)
  callable_price <- price_at_zero(first_period$callable)
  list(
    bullet_price = bullet_price,
    callable_price = callable_price,
    issuer_call_value = bullet_price - callable_price,
    decisions = dplyr::bind_rows(first_period$decisions),
    grid = grid
  )
}

model_result <- compute_callable_bond_LRL(

)

II-8.7 Bermudan Swaptionへの拡張

固定クーポン債を発行体が償還できる権利は、金利低下局面で価値が増える点で、固定を受け取るReceiver Swaptionと似る。複数行使日の権利はBermudan型である。ただし、Callable BondとBermudan Receiver Swaptionを同額の権利とみなすには、債券クーポンとスワップの固定・変動キャッシュフロー、元本、行使日、決済とコール価格の対応を厳密に合わせる必要がある。この章では価格を機械的に置き換えない。

Hull–White 1因子では継続価値を一つの状態の関数として計算でき、Tree、有限差分、状態格子の積分などが候補になる。本章は状態格子と正規求積を用いた。一方、BGM/LMMやRFR向けFMMを使って多数のフォワード金利を動かす場合は、共通の測度のもとで経路を作り、行使日時点の情報に条件づけた継続価値を回帰などで推定する方法がある。将来の経路ごとに実現した利益を直接比べ、過去の行使を決める方法は使わない。

実取引への拡張では、OIS割引と予測カーブの分離、約定上の通知日と利払い日のずれ、クリーン価格と経過利息の扱いを揃える。

II-8.8 MBSのプリペイメント

住宅ローンを裏付けとするMBSでは、債務者が一部または全部を繰り上げて返済できる。プール全体では、各月の予定元本返済とは別にプリペイメントが生じ、投資家は元本を早く受け取る。発行体が契約日の一括償還を選ぶ前節のCallable Bondと異なり、キャッシュフローを月次のプール残高から組み立てる。ここでは元本と利息がそのまま投資家に支払われる簡略なパススルーを扱い、デフォルトと損失は含めない。

米国の 100% PSA をベンチマークとする月齢 \(m\) の年率換算プリペイメント率（CPR）は、Ginnie Mae の商品説明 に沿って

\[\mathrm{CPR}^{\mathrm{PSA}}_m =\min(0.002m,0.06),\qquad \mathrm{SMM}_m=1-(1-\mathrm{CPR}_m)^{1/12}.\]

月次予定元本を \(A_m\)、月初元本を \(B_{m-1}\) とすると、プリペイメント元本は \(U_m=(B_{m-1}-A_m)\mathrm{SMM}_m\)、月末元本は \(B_m=B_{m-1}-A_m-U_m\)。基準PSAだけでは借換えインセンティブを表せないため、以下の数値例では住宅ローンの約定金利 \(c\)、月ごとに変化する借換え金利 \(f_m\)、借換えに伴う金利換算費用 \(k\) から、教材用の仮定

\[\mathrm{CPR}_m=\min\{0.60,\alpha\,\mathrm{CPR}^{\mathrm{PSA}}_m \exp[\beta(c-f_m-k)]\}\]

を置く。\(\alpha=1\) はPSAベンチマークの速度、\(\alpha=0\) はプリペイメントなしである。\(\beta\) と上限は市場での推定値ではない。経過月数、借換え費用と金利シナリオが将来の各月のプリペイメントを変え、元本残高の減少は翌月以降の利息と予定元本に反映される。

compute_mbs_cashflows_LRL <- function(
  original_balance, mortgage_rate, pass_through_rate,
  refinance_rate, maturity_months = 360L, incentive_sensitivity = 20,
  refinancing_cost_rate = 0, psa_multiplier = 1
) {
  stopifnot(
    original_balance > 0, maturity_months > 0,
    mortgage_rate >= 0, pass_through_rate >= 0,
    all(is.finite(refinance_rate)), all(refinance_rate >= 0),
    length(refinance_rate) %in% c(1L, maturity_months),
    incentive_sensitivity >= 0, refinancing_cost_rate >= 0,
    psa_multiplier >= 0,
    pass_through_rate <= mortgage_rate
  )
  refinance_path <- rep(refinance_rate, length.out = maturity_months)
  monthly_rate <- mortgage_rate / 12
  monthly_payment <- if (monthly_rate == 0) {
    original_balance / maturity_months
  } else {
    original_balance * monthly_rate /
      (1 - (1 + monthly_rate)^(-maturity_months))
  }
  balance <- original_balance
  rows <- vector("list", maturity_months)
  for (m in seq_len(maturity_months)) {
    begin_balance <- balance
    loan_interest <- begin_balance * monthly_rate
    scheduled_principal <- min(
      begin_balance, max(0, monthly_payment - loan_interest)
    )
    if (m == maturity_months) scheduled_principal <- begin_balance
    base_cpr <- min(0.002 * m, 0.06)
    cpr <- min(
      0.60, psa_multiplier * base_cpr * exp(
        incentive_sensitivity * (
          mortgage_rate - refinance_path[m] - refinancing_cost_rate
        )
      )
    )
    smm <- 1 - (1 - cpr)^(1 / 12)
    prepaid_principal <- (begin_balance - scheduled_principal) * smm
    balance <- max(0, begin_balance - scheduled_principal - prepaid_principal)
    rows[[m]] <- tibble::tibble(
      month = m, begin_balance = begin_balance,
      refinance_rate = refinance_path[m],
      cpr = cpr, smm = smm,
      interest = begin_balance * pass_through_rate / 12,
      scheduled_principal = scheduled_principal,
      prepaid_principal = prepaid_principal,
      end_balance = balance,
      cashflow = begin_balance * pass_through_rate / 12 +
        scheduled_principal + prepaid_principal
    )
  }
  dplyr::bind_rows(rows)
}

次は第7章の Hull–White モデルで月次金利経路を作り、各経路の借換え金利からプリペイメントを計算する例である。短期金利に一律3%を加えて借換え金利の代理変数とする。実際の住宅ローン金利は長期スワップ金利、貸出スプレッド、金融機関の提示条件などから推定する必要がある。このコードは月次格子の短期金利による割引近似を使い、入力パラメータは市場キャリブレーション値ではない。

simulate_mbs_rates_LRL <- function(
  number_of_paths = 200L, maturity_months = 360L,
  flat_rate = 0.02, mean_reversion = 0.15,
  volatility = 0.012, seed = 48L
) {
  stopifnot(number_of_paths %% 2L == 0L, number_of_paths > 0,
    maturity_months > 0, mean_reversion > 0, volatility >= 0)
  set.seed(seed)
  dt <- 1 / 12
  b <- exp(-mean_reversion * dt)
  step_sd <- volatility * sqrt(
    (1 - b^2) / (2 * mean_reversion)
  )
  shocks <- matrix(
    stats::rnorm(number_of_paths / 2L * maturity_months),
    nrow = number_of_paths / 2L
  )
  shocks <- rbind(shocks, -shocks)
  short_rates <- matrix(0, number_of_paths, maturity_months)
  x <- rep(0, number_of_paths)
  for (m in seq_len(maturity_months)) {
    x <- b * x + step_sd * shocks[, m]
    time <- m * dt
    phi <- flat_rate + volatility^2 / (2 * mean_reversion^2) *
      (1 - exp(-mean_reversion * time))^2
    short_rates[, m] <- phi + x
  }
  short_rates
}

OAS \(z\) に対応する価格は、経路 \(j\) の月 \(m\) のキャッシュフロー \(CF_m^{(j)}\) を使い、

\[P(z)=\mathbb E^{\mathbb Q}\!\left[ \sum_{m=1}^{360}CF_m \exp\!\left(-\int_0^{m/12}(r_s+z)\,ds\right) \right]\]

と計算する。市場価格があれば \(P(z)\) を一致させる \(z\) を解く。金利経路で変化するキャッシュフローと割引係数には相関があるため、経路ごとの現在価値を計算してから平均する。平均キャッシュフローだけを固定曲線で割り引く場合は別の簡約法となる。

II-8.8.1 PSA別のOASと価格の関係

MathWorks の Computing Option-Adjusted Spread は、0・50・100% PSA に対してゼロカーブと取引価格から OAS を解く例を示す。以下では同じ比較の設計を使う。架空の価格を95（ディスカウント）と105（プレミアム）に設定し、金利を4%で固定して PSA ごとに価格を一致させるスプレッドを求める。これはキャッシュフローをあらかじめ確定する静的なOAS感応度であり、前節の金利経路を使った OAS とは区別する。

compute_mbs_static_oas_LRL <- function(
  tbl_cashflows, market_price, zero_rate = 0.04
) {
  stopifnot(market_price > 0, is.finite(zero_rate))
  price_for_spread <- function(spread) {
    sum(tbl_cashflows$cashflow * exp(
      -(zero_rate + spread) * tbl_cashflows$month / 12
    ))
  }
  stats::uniroot(
    function(spread) price_for_spread(spread) - market_price,
    interval = c(-0.10, 0.30),
    extendInt = "yes"
  )$root
}

第II-7章 ショートレートモデルとフォワード金利モデル
第II-9章 金利為替系デリバティブ
