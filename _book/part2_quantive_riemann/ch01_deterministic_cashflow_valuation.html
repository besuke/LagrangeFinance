第II-1章 債券評価と金利リスクの基礎

金融では、異なる時点に発生する金額をそのまま比較することはできない。今日受け取る100円と1年後に受け取る100円では、運用可能期間や金利が異なるため、経済的な価値も異なるからである。そこで、時点の異なるキャッシュフローを評価する場合には、将来の金額を現在価値へ割り引くか、現在の金額を将来価値へ換算し、同一時点の価値にそろえる必要がある。金融商品の価格評価では、通常、将来のすべてのキャッシュフローを評価時点の現在価値へ換算する。

金融商品の評価では、理論的な価格式を理解するだけでなく、市場で定められたマーケットコンベンションを正確に理解し、それを計算システムとして実装することが重要である。特に債券は、利払日、日数計算規則、経過利子、受渡日、価格表示、利回り表示、端数処理などが市場慣行として規格化されている。これらを正確に反映しなければ、理論的に正しい価格式を用いても実際の市場で用いられる単価や利回りを再現できない。

日本の債券市場では、長年にわたり価格そのものだけでなく利回りを中心として取引条件を表現する慣行があり、とりわけ単利利回りが広く用いられてきた。単利利回りは、将来の各キャッシュフローを支払時点ごとに割り引く複利評価と比べると簡易な指標であるが、市場慣行として重要な役割を果たしている。このため、本章では市場で用いられる単利利回りから債券単価を求め、その単価を基準として複利利回りを逆算する流れを出発点とする。

金融市場では、すべての満期についてゼロクーポン金利が直接観測されるわけではない。TONAR OIS市場で主として観測されるのは、各満期において固定レッグと変動レッグの現在価値を等しくするパーレートである。金融商品の評価では、このパーレートからディスカウントファクターを導出し、スポットレートおよびフォワードレートからなる金利期間構造へ変換する必要がある。

そこで本章では、まず パーレート → ディスカウントファクター → スポットレート → フォワードレート という導出関係を確認する。さらに、順イールド、逆イールドおよびフラットカーブについて、三つの金利の大小関係を直観と数式の両面から理解する。その後、同一の40年債を一貫して用い、単利利回り → 債券単価 → 複利利回り → フラットイールド評価 → 連続複利による再評価 → Zスプレッド → アセットスワップ → 金利感応度へと評価を展開する。最後に、クリーンプライスから複利利回りを逆算する問題を求根問題として捉え、複数の数値解法を比較する。

II-1.1 イールドカーブの基本

II-1.1.1 イールドカーブとは何か

イールドカーブは、横軸に満期、縦軸に金利をとり、金利の期間構造を表したものである。金利は市場全体に一つだけ存在する数字ではなく、1年、5年、10年、30年といった期間ごとに異なる。長期金利が短期金利より高い右上がりの形状を順イールド、低い右下がりの形状を逆イールド、満期による差が小さい形状をフラットカーブという。

同じ市場の金利期間構造にも、パーレート、スポットレート、フォワードレートという複数の表現がある。これらは別々の金利ではなく、同一のイールドカーブを異なる角度から見たものである。

II-1.1.2 パーレート・スポットレート・フォワードレート

パーレートは、債券であれば価格を額面と等しくし、スワップであれば契約時の価値をゼロにする固定金利である。市場で観測されるクーポン付き商品の金利を表す。

スポットレートは、評価時点から特定の将来時点までのゼロクーポン金利である。満期まで途中の利払いがない一つのキャッシュフローを割り引くための金利であり、金融商品の各キャッシュフローを個別に評価する基礎となる。

フォワードレートは、将来の特定期間に対応する金利である。スポットレートが評価時点から満期までの平均的な金利を表すのに対し、フォワードレートは将来の局所的な金利を表す。

II-1.1.3 TONAR OISのパーレート

満期 \(T_n\) のTONAR OISパーレートを \(S_n\)、固定レッグの各計算期間を \(\alpha_i\)、ディスカウントファクターを \(DF(T_i)\) とする。固定レッグの現在価値は、想定元本を1とすれば、

\[PV_{\mathrm{fixed}} = S_n\sum_{i=1}^{n}\alpha_iDF(T_i)\]

と表される。一方、標準的なOISの変動レッグの現在価値は、概念的に

\[PV_{\mathrm{float}} = 1-DF(T_n)\]

である。パーレートでは両者が等しいため、

\[\boxed{ S_n = \frac{1-DF(T_n)} {\displaystyle\sum_{i=1}^{n}\alpha_iDF(T_i)} }\]

となる。TONAR OISの市場クォートは、この固定レッグと変動レッグを釣り合わせるパーレートである。

II-1.1.4 パーレートからディスカウントファクターの導出

上式を満期 \(T_n\) のディスカウントファクターについて解くと、

\[\boxed{ DF(T_n) = \frac{ 1-S_n\displaystyle\sum_{i=1}^{n-1}\alpha_iDF(T_i) }{1+S_n\alpha_n} }\]

となる。短い満期で求めたディスカウントファクターを使って、次の満期の値を順番に求めていく手続きがブートストラップである。本章では導出の意味を理解することに重点を置き、実際のマーケットコンベンションと補間を含むカーブ構築は第II-2章で扱う。

II-1.1.5 ディスカウントファクターからスポットレート

ディスカウントファクターは、将来の1単位の金額を評価時点の価値へ変換する倍率である。時点 \(t_i\) のキャッシュフローを \(CF_i\) とすれば、金融商品の現在価値は、

\[PV=\sum_{i=1}^{n}CF_iDF(t_i)\]

となる。連続複利のスポットレートを \(z(T)\) とすると、

\[DF(T)=\exp\{-z(T)T\}\]

したがって、

\[\boxed{ z(T)=-\frac{\log DF(T)}{T} }\]

である。スポットレートは、評価時点から満期までの期間全体を表す平均的な金利と捉えることができる。

II-1.1.6 スポットレートからフォワードレート

インスタント・フォワードレートを \(f(T)\) とすると、

\[DF(T) = \exp\left\{-\int_0^T f(u)\,du\right\}\]

である。したがって、スポットレートは、現在から満期までのフォワードレートの平均として、

\[\boxed{ z(T)=\frac{1}{T}\int_0^T f(u)\,du }\]

と表される。また、

\[\boxed{ f(T) = -\frac{\partial\log DF(T)}{\partial T} = z(T)+T\frac{\partial z(T)}{\partial T} }\]

である。この微分関係により、イールドカーブの傾きとスポットレート、フォワードレートの大小関係が結びつく。

II-1.2 イールドカーブの形状と三つの金利

II-1.2.1 順イールド

スポットレートカーブが右上がりなら、\(z'(T)>0\) である。したがって、

\[f(T)=z(T)+Tz'(T)>z(T)\]

となる。スポットレートが現在から満期までの平均勾配、フォワードレートが満期付近の局所的な勾配だと考えれば、上り坂が次第に急になるとき、局所的な勾配がそれまでの平均を上回ることは直観的にも明らかである。

パーレートとスポットレートの関係は、途中で利払いのある債券と、満期まで何も支払わないゼロクーポン債を比べると理解しやすい。額面を1、満期を2年、年1回払いのクーポンを \(c\) とすれば、パー債は、

\[1=cDF(1)+(1+c)DF(2)\]

を満たすため、

\[c=\frac{1-DF(2)}{DF(1)+DF(2)}\]

となる。順イールドでは、パー債は相対的に低い短期金利で評価される1年後のクーポンを先に回収できる。この途中キャッシュフローの現在価値があるため、価格を額面1にするクーポン率は、すべての収益を2年後に受け取るゼロクーポン債の2年スポットレートより低くてよい。

したがって、滑らかで単調な順イールドでは、典型的に、

\[\boxed{ \text{パーレート} < \text{スポットレート} < \text{フォワードレート} }\]

となる。

II-1.2.2 逆イールド

スポットレートカーブが右下がりなら、\(z'(T)<0\) であり、

\[f(T)=z(T)+Tz'(T)<z(T)\]

となる。スポットレートには、それ以前の高い短期金利が平均として残るため、満期付近のフォワードレートはスポットレートより低い。

また、パー債が途中で受け取るクーポンには短期側の高い金利が反映される。このため、途中利払いのないゼロクーポン債のスポットレートより、価格を額面にするパーレートの方が高くなる。したがって、滑らかで単調な逆イールドでは、典型的に、

\[\boxed{ \text{パーレート} > \text{スポットレート} > \text{フォワードレート} }\]

となる。

II-1.2.3 フラットカーブ

スポットレートが満期によらず一定なら、\(z'(T)=0\) なので、\(f(T)=z(T)\) となる。複利方式と支払頻度をそろえた理想的な条件では、

\[\boxed{ \text{パーレート} = \text{スポットレート} = \text{フォワードレート} }\]

となる。

II-1.2.5 順イールド・逆イールドの模式図

次の数値例では、年1回複利のスポットレートを滑らかに上昇または低下させ、対応するディスカウントファクター、パーレートおよび1年フォワードレートを計算する。

tbl_curve_shapes <- tidyr::crossing(
  curve_shape = c("順イールド", "逆イールド"),
  maturity = 1:10
) |>
  dplyr::group_by(curve_shape) |>
  dplyr::mutate(
    spot_rate = dplyr::if_else(
      curve_shape == "順イールド",
      0.01 + 0.002 * maturity,
      0.035 - 0.0015 * maturity
    ),
    discount_factor = (1 + spot_rate)^(-maturity),
    previous_discount = dplyr::lag(
      discount_factor,
      default = 1
    ),
    forward_rate = (
      previous_discount /
        discount_factor
    ) - 1,
    par_rate = (
      1 - discount_factor
    ) / cumsum(discount_factor)
  ) |>
  dplyr::ungroup() |>
  dplyr::select(
    curve_shape,
    maturity,
    par_rate,
    spot_rate,
    forward_rate
  ) |>
  tidyr::pivot_longer(
    cols = c(
      par_rate,
      spot_rate,
      forward_rate
    ),
    names_to = "curve_type",
    values_to = "rate"
  ) |>
  dplyr::mutate(
    curve_type = dplyr::recode(
      curve_type,
      par_rate = "パーレート",
      spot_rate = "スポットレート",
      forward_rate = "フォワードレート"
    )
  )

この大小関係は、複利方式と支払頻度をそろえ、金利期間構造が滑らかかつ単調に上昇または下降する典型的な状況を想定している。複雑なカーブ形状や異なる市場慣行のもとですべての満期について機械的に成立する恒等式ではない。しかし、パーレートは途中キャッシュフローを含む金利、スポットレートは満期までの平均的な金利、フォワードレートは満期付近の局所的な金利であるという違いを理解すれば、三つのカーブの位置関係を直観的に読むことができる。

II-1.3.3 債券市場のマーケットコンベンション

債券計算では、日数計算規則、休日カレンダー、営業日調整、受渡日、利払頻度、価格表示、利回り表示および端数処理を一体として扱う必要がある。計算式だけが一致していても、マーケットコンベンションが異なれば市場で用いられる値とは一致しない。

代表的な日数計算規則にはActual/365 Fixed、Actual/360、Actual/Actual ICMA、Actual/Actual ISDA、30/360 Bond Basisなどがある。債券のクーポン計算と金利カーブの時間軸では、同じ日数計算規則を用いるとは限らない。この区別は、後続章で金利カーブを構築するときにも重要となる。

II-1.4 債券単価と市場利回り

II-1.4.1 単利利回りと債券単価

日本の公社債市場では単利利回りが広く用いられてきた。額面100円、年間クーポン額を \(C\)、償還価格を \(R\)、単価を \(P\)、残存年数を \(T\) とすると、単利の最終利回り \(Y\) は

\[Y= \frac{ C+\dfrac{R-P}{T} }{ P } \times 100\]

で表される。

逆に、単利利回り \(y=Y/100\) から単価を求めると、

\[P= \frac{ C+\dfrac{R}{T} }{ y+\dfrac{1}{T} }\]

となる。実務では残存日数、残存年数および単価について所定の端数処理を適用するため、計算システムでは式だけでなく丸め・切り捨て規則まで実装する必要がある。以下では、受渡日を2022年4月1日に統一し、単利利回り6.515%から日本市場の計算規則に従って求めた単価を、本章以降のクリーンプライスとして一貫して使用する。

II-1.4.2 経過利子とクリーンプライス

債券市場で表示される単価は通常クリーンプライスである。受渡時には、直前利払日から受渡日までに発生した経過利子を加える。

\[\text{Dirty Price} = \text{Clean Price} + \text{Accrued Interest}\]

II-1.4.3 ダーティプライスと受渡金額

クリーンプライスは市場での価格比較に適している一方、実際の受渡金額および将来キャッシュフローとの現在価値比較にはダーティプライスを用いる。したがって、利回りやスプレッドを逆算するときには、どの価格を入力としているかを明確にする必要がある。

II-1.5 利回りによる債券評価

II-1.5.1 単利利回りによる評価

単利利回りは、クーポン収入と償還差損益を残存期間で年率化し、現在の単価に対する収益率として表す。計算が簡潔である一方、各キャッシュフローの発生時点を個別に割り引くものではない。

II-1.5.2 複利利回りによる評価

複利利回りでは、各キャッシュフローをその支払時点まで複利で割り引く。市場単価を \(P\)、キャッシュフローを \(CF_i\)、支払時点を \(t_i\) とすると、複利利回り \(y\) は概念的に

\[P = \sum_{i=1}^{n} \frac{CF_i}{(1+y/m)^{m t_i}}\]

を満たす利回りである。ここで \(m\) は年間複利回数である。

本章では、ここで用いる市場単価を任意に与えるのではなく、前節の単利利回りから求めたクリーンプライスとする。したがって、計算の流れは 単利利回り → クリーンプライス → 複利利回り となる。

II-1.6.3 アセットスワップ

アセットスワップでは、固定利付債のキャッシュフローを金利スワップの変動金利キャッシュフローへ変換し、債券をスワップ市場の基準金利と比較する。したがって、単純な「債券利回り－スワップレート」ではなく、債券価格、経過利子、固定クーポン、スワップの割引係数および変動金利レグの現在価値を同じ評価時点で整合させる必要がある。

本章ではアセットスワップの位置づけと計算構造を確認し、実際のOIS・IRSカーブ構築およびマルチカーブ評価は第II-3章で扱う。第II-3章で構築したスワップカーブを用いることで、本節の債券評価を実際のIRS市場との相対価値評価へ接続できる。

II-1.6.4 債券利回りとスワップレートの比較

債券の複利利回りと同年限のスワップレートとの差は相対価値を見るための直感的な指標となるが、これはアセットスワップ・スプレッドそのものではない。アセットスワップではキャッシュフロー単位の現在価値を一致させる必要がある。

この区別を明確にすることで、単利利回りから始まった債券評価を、金利スワップと共通の割引評価体系へ接続できる。

II-1.7 債券の金利感応度

II-1.7.1 デュレーション

デュレーションは、債券キャッシュフローの回収時点を現在価値で加重平均した指標である。債券の残存期間だけではなく、クーポンと利回りにも依存する。

II-1.7.2 修正デュレーション

修正デュレーションは、利回り変化に対する価格の一次感応度を表す。

\[\frac{\Delta P}{P} \approx -D_{\mathrm{mod}}\Delta y\]

# VBA定義に合わせ、利回り Y は「%」単位で扱う。
# 例: 6.71047990% は Y = 6.71047990。
#
# P      : 単価（円 / 額面100円）
# dP/dY  : 利回り1%変化あたりの単価変化（円）
# BPV    : -dP/dY。数値はそのまま「銭 / bp」と一致する。
#
# 一般的な Modified Duration（利回りを小数で扱う定義）は
#   D_mod = -100 / P * dP/dY
# となる。

compute_bond_price_LRL <- function(
  compound_yield_pct,
  coupon_rate_pct,
  remaining_years
) {
  if (compound_yield_pct == 0) {
    return(
      face_amount +
        coupon_rate_pct * remaining_years
    )
  }

  discount_factor_half_year <- (
    1 + compound_yield_pct / 200
  )^(-1)

  face_amount * (
    coupon_rate_pct / compound_yield_pct *
      (
        1 - discount_factor_half_year^(
          2 * remaining_years
        )
      ) +
      discount_factor_half_year^(2 * remaining_years)
  )
}

compute_bond_price_derivative_LRL <- function(
  compound_yield_pct,
  coupon_rate_pct,
  remaining_years
) {
  if (compound_yield_pct == 0) {
    return(
      -(
        coupon_rate_pct * remaining_years *
          (2 * remaining_years + 1) / 400 +
          remaining_years
      )
    )
  }

  discount_factor_half_year <- (
    1 + compound_yield_pct / 200
  )^(-1)

  -100 * coupon_rate_pct / compound_yield_pct^2 *
    (
      1 - discount_factor_half_year^(
        2 * remaining_years
      )
    ) -
    (1 - coupon_rate_pct / compound_yield_pct) *
      remaining_years *
      discount_factor_half_year^(
        2 * remaining_years + 1
      )
}

compute_bond_price_second_derivative_LRL <- function(
  compound_yield_pct,
  coupon_rate_pct,
  remaining_years
) {
  if (compound_yield_pct == 0) {
    return(
      remaining_years *
        (2 * remaining_years + 1) / 20000 *
        (
          coupon_rate_pct *
            (remaining_years + 1) / 3 +
            100
        )
    )
  }

  discount_factor_half_year <- (
    1 + compound_yield_pct / 200
  )^(-1)

  remaining_years *
    (2 * remaining_years + 1) / 200 *
    (1 - coupon_rate_pct / compound_yield_pct) *
    discount_factor_half_year^(
      2 * remaining_years + 2
    ) -
    2 * coupon_rate_pct * remaining_years /
      compound_yield_pct^2 *
      discount_factor_half_year^(
        2 * remaining_years + 1
      ) +
    200 * coupon_rate_pct / compound_yield_pct^3 *
      (
        1 - discount_factor_half_year^(
          2 * remaining_years
        )
      )
}

デュレーションが価格・利回り曲線の一次の傾きを表すのに対し、コンベクシティは二次の曲率を表す。利回り変化が大きくなるほど、一次近似だけでは価格変化を十分に説明できなくなる。

II-1.7.4 BPVによる価格感応度

本章ではVBAの定義に合わせ、複利利回り \(Y\) を %単位で扱う。したがって、\(Y=6.71047990\) は6.71047990%を意味する。

単価 \(P\) を「円／額面100円」で表すと、

\[\mathrm{BPV} = -\frac{\partial P}{\partial Y}\]

と定義できる。この \(-\partial P/\partial Y\) は「円／1%」であるが、1bp = 0.01%、1円 = 100銭であるため、数値はそのまま 銭／bp と一致する。

本例では、

\[-\frac{\partial P}{\partial Y} \approx 15.1421\]

であるため、BPVは約15.1421銭／bp、すなわち0.151421円／bpである。

一般的なModified Durationは利回りを小数で扱う定義なので、

\[D_{\mathrm{mod}} = -\frac{100}{P} \frac{\partial P}{\partial Y}\]

となる。VBAで%単位の微分値を扱う場合には、この100倍の換算を明示する必要がある。

II-1.8.2 ニュートン・ラフソン法

ニュートン・ラフソン法は、現在の推定値における関数値と微分値から次の推定値を求める。

\[y_{k+1} = y_k - \frac{f(y_k)}{f'(y_k)}\]

ここではVBAと同じく \(Y\) を %単位で扱う。つまり、6.71047990% は \(Y=6.71047990\) とする。小数表記の \(0.067104799\) ではない点が重要である。

半年複利の割引係数を

\[\alpha= \left( 1+\frac{Y}{200} \right)^{-1}\]

とおく。

残存年数を \(T\)、年2回払いのクーポン率を \(C\)（%）、額面を100とすると、\(Y\neq0\) の場合の債券単価は

\[P = 100 \left\{ \frac{C}{Y} \left( 1-\alpha^{2T} \right) + \alpha^{2T} \right\}.\]

また、\(Y=0\) の場合は

\[P=100+CT\]

となる。

この価格関数を、%単位の利回り \(Y\) で微分する。VBAではBPVを

\[\boxed{ \mathrm{BPV} = -\frac{\partial P}{\partial Y} }\]

と定義している。

ここで \(\partial P/\partial Y\) の単位は「円／1 percentage point」である。すなわち、利回りが1.00%変化したときの、額面100円あたりの単価変化を表す。

一方、

\[1\mathrm{bp}=0.01\%\]

であり、

\[1\text{円}=100\text{銭}\]

である。

したがって、利回り変化をbp、単価変化を銭で表すと、

\[\Delta p(\text{銭}) = \Delta P(\text{円}) \times 100\]

である。

また、

\[\Delta Y(\%) = \frac{\Delta y(\mathrm{bp})}{100}\]

なので、

\[\Delta p(\text{銭}) \approx \frac{\partial P}{\partial Y} \Delta Y(\%) \times 100\]

に代入すると、

\[\Delta p(\text{銭}) \approx \frac{\partial P}{\partial Y} \frac{\Delta y(\mathrm{bp})}{100} \times 100\]

となる。したがって、

\[\boxed{ \Delta p(\text{銭}) \approx \frac{\partial P}{\partial Y} \Delta y(\mathrm{bp}) }\]

であり、1bpの変化に対しては、

\[\boxed{ \mathrm{BPV}(\text{銭}/\mathrm{bp}) = -\frac{\partial P}{\partial Y} }\]

となる。

つまり、%単位で計算した \(-\partial P/\partial Y\) の数値そのものが、銭／bpで表したBPVになる。

例えば本章の40年債では、

\[-\frac{\partial P}{\partial Y} \approx 15.1421\]

なので、

\[\mathrm{BPV} \approx 15.1421\ \text{銭}/\mathrm{bp}\]

である。円単位では、

\[15.1421\text{銭} = 0.151421\text{円}\]

なので、

\[\mathrm{BPV} \approx 0.151421\ \text{円}/\mathrm{bp}\]

となる。

同様に、Convexityでは価格関数の2階微分を用いる。VBAの定義では \(Y\) を%単位で扱うため、

\[\mathrm{Convexity}_{\%} = \frac{1}{P+\mathrm{Acc}} \frac{\partial^2 P}{\partial Y^2}\]

である。

ただし、一般的なConvexityは利回りを小数単位で扱う。そのため、%単位の2階微分から通常のConvexityへ換算する場合には、

\[\boxed{ \mathrm{Convexity} = \frac{10000}{P+\mathrm{Acc}} \frac{\partial^2 P}{\partial Y^2} }\]

となる。1階微分では100倍、2階微分では \(100^2=10000\) 倍になる点が重要である。

また、利回り変化をbp、単価変化を銭で表した2次近似では、

\[\Delta p(\text{銭}) \approx \frac{\partial P}{\partial Y} \Delta y(\mathrm{bp}) + \frac{1}{2} \frac{1}{100} \frac{\partial^2 P}{\partial Y^2} \left\{ \Delta y(\mathrm{bp}) \right\}^2.\]

したがって、bp・銭単位で2次項を使う場合には、2階微分を

\[\boxed{ \frac{\partial^2 p} {\partial y(\mathrm{bp})^2} = \frac{1}{100} \frac{\partial^2 P}{\partial Y^2} }\]

として扱う。

\(Y=0\) の場合

VBAでは \(Y=0\) を別ケースとして明示的に扱う。半年複利の割引係数は

\[\alpha= \left( 1+\frac{Y}{200} \right)^{-1}\]

であり、\(Y=0\) では \(\alpha=1\) となる。

債券単価は、

\[\boxed{ P=100+CT }\]

となる。

1階微分は、

\[\boxed{ \left. \frac{\partial P}{\partial Y} \right|_{Y=0} = - \left\{ \frac{CT(2T+1)}{400} + T \right\} }\]

である。

したがって、

\[\boxed{ \mathrm{BPV}_{Y=0} = - \left. \frac{\partial P}{\partial Y} \right|_{Y=0} = \frac{CT(2T+1)}{400} + T }\]

となり、この数値はVBAの単位規約ではそのまま銭／bpである。

2階微分は、

\[\boxed{ \left. \frac{\partial^2 P}{\partial Y^2} \right|_{Y=0} = \frac{T(2T+1)}{20000} \left\{ \frac{C(T+1)}{3} + 100 \right\} }\]

である。

したがって、\(Y=0\) のModified Durationは、

\[\boxed{ D_{\mathrm{mod},Y=0} = -\frac{100}{P+\mathrm{Acc}} \left. \frac{\partial P}{\partial Y} \right|_{Y=0} }\]

Convexityは、

\[\boxed{ \mathrm{Convexity}_{Y=0} = \frac{10000}{P+\mathrm{Acc}} \left. \frac{\partial^2 P}{\partial Y^2} \right|_{Y=0} }\]

となる。

なお、受渡日が利払日で経過利子 \(\mathrm{Acc}=0\) の場合は、上式の \(P+\mathrm{Acc}\) は単に \(P\) となる。

\(Y\neq0\) の解析微分

\(Y\neq0\) では、

\[P = 100 \left\{ \frac{C}{Y} (1-\alpha^{2T}) + \alpha^{2T} \right\}, \qquad \alpha= \left(1+\frac{Y}{200}\right)^{-1}\]

を直接微分する。

VBAで使用する1階微分は、

\[\boxed{ \frac{\partial P}{\partial Y} = -100\frac{C}{Y^2} (1-\alpha^{2T}) - \left( 1-\frac{C}{Y} \right) T\alpha^{2T+1} }\]

である。

2階微分は、

\[\boxed{ \frac{\partial^2P}{\partial Y^2} = \frac{T(2T+1)}{200} \left( 1-\frac{C}{Y} \right) \alpha^{2T+2} - 2\frac{CT}{Y^2} \alpha^{2T+1} + 200\frac{C}{Y^3} (1-\alpha^{2T}) }\]

となる。

これにより、価格 \(P\)、BPV、Modified Duration、Convexityをすべて同一の価格関数と同一の%単位規約から計算できる。

さらに、一般的なModified Durationは利回りを小数単位で定義するため、VBAの%単位微分との関係は

\[D_{\mathrm{mod}} = -\frac{100}{P+\mathrm{Acc}} \frac{\partial P}{\partial Y}\]

である。受渡日が利払日で経過利子が0なら、

\[D_{\mathrm{mod}} = -\frac{100}{P} \frac{\partial P}{\partial Y}\]

となる。

ニュートン・ラフソン法では、この解析微分 \(\partial P/\partial Y\) をそのまま傾きとして使用する。価格方程式

\[f(Y)=P(Y)-P_{\mathrm{market}}=0\]

に対して、

\[Y_{n+1} = Y_n - \frac{ P(Y_n)-P_{\mathrm{market}} }{ \partial P/\partial Y }\]

と更新する。この式では \(Y\) 自体が%単位なので、途中で \(10^{-4}\) や100を追加で掛ける必要はない。

# ニュートン・ラフソン法は、VBAと同じ解析微分 dP/dY をそのまま使用する。
# Yの単位は%なので、更新式にも追加の1e-4換算は不要。

compute_bond_yield_newton_LRL <- function(
  initial_yield_pct = benchmark_simple_yield_pct,
  tolerance = 1e-12,
  max_iter = 100L
) {
  purrr::reduce(
    seq_len(max_iter),
    .init = list(
      yield_pct = initial_yield_pct,
      converged = FALSE
    ),
    .f = function(state, iteration) {
      if (state$converged) {
        return(state)
      }

      objective_value <- compute_bond_yield_objective_LRL(
        state$yield_pct
      )

      )

      list(
        yield_pct = next_yield_pct,
        converged = abs(objective_value) < tolerance
      )
    }
  )$yield_pct
}

II-1.8.3 二分法

二分法は、根を挟む区間を半分ずつ狭めていく方法である。収束速度はニュートン・ラフソン法より遅いが、適切に根を挟む区間を設定すれば安定して解を求められる。

compute_bond_yield_bisection_LRL <- function(
  lower = -1,
  upper = 20,
  tolerance = 1e-12,
  max_iter = 200L
) {
  result <- purrr::reduce(
    seq_len(max_iter),
    .init = list(
      lower = lower,
      upper = upper,
      root = NA_real_,
      converged = FALSE
    ),
    .f = function(state, iteration) {
      if (state$converged) {
        return(state)
      }

      midpoint <- (
        state$lower + state$upper
      ) / 2

      objective_lower <- compute_bond_yield_objective_LRL(
        state$lower
      )
      objective_midpoint <- compute_bond_yield_objective_LRL(
        midpoint
      )

      next_state <- if (
        sign(objective_lower) == sign(objective_midpoint)
      ) {
        list(
          lower = midpoint,
          upper = state$upper
        )
      } else {
        list(
          lower = state$lower,
          upper = midpoint
        )
      }

      list(
        lower = next_state$lower,
        upper = next_state$upper,
        root = midpoint,
        converged = abs(objective_midpoint) < tolerance ||
          abs(state$upper - state$lower) < tolerance
      )
    }
  )

  result$root
}

yield_bisection_result <- compute_bond_yield_bisection_LRL()

II-1.8.5 多項式求根法

規則的な固定利付債では、

\[x= \frac{1}{1+Y/200}\]

と置くことで、価格方程式を \(x\) の多項式として表現できる。この場合、Rの polyroot() を利用してすべての複素根を求め、経済的に意味のある実根を選択できる。

40年・半年払いでは80次多項式となるため、短期債の場合よりも多項式求根法の計算負荷が明確になる。

compute_bond_yield_polyroot_LRL <- function() {
  poly_coefficients <- c(
    -benchmark_market_price,
    rep(
      benchmark_coupon,
      benchmark_periods - 1L
    ),
    benchmark_coupon + benchmark_face
  )

  poly_roots <- polyroot(poly_coefficients)

  valid_poly_roots <- poly_roots[
    abs(Im(poly_roots)) < 1e-10 &
      Re(poly_roots) > 0
  ]

  yield_candidates <- (
    1 / Re(valid_poly_roots) - 1
  ) * 200

  yield_candidates[
    which.min(
      abs(
        purrr::map_dbl(
          yield_candidates,
          compute_bond_yield_objective_LRL
        )
      )
    )
  ]
}

compute_bond_yield_benchmark_LRL <- function(
  method,
  solver,
  result,
  price_function = NULL
) {
  timing <- system.time(
    purrr::map_dbl(
      seq_len(benchmark_repetitions),
      ~ solver()
    )
  )

  price_error <- if (is.null(price_function)) {
    NA_real_
  } else {
    price_function(result) -
      benchmark_market_price
  }

  tibble::tibble(
    method = method,
    yield = result,
    price_error = price_error,
    repetitions = benchmark_repetitions,
    elapsed_ms = unname(timing[["elapsed"]]) * 1000,
    average_us = (
      unname(timing[["elapsed"]]) *
        1e6 /
        benchmark_repetitions
    )
  )
}

以上の結果から、本例では Brent法 → ニュートン・ラフソン法 → 二分法 → polyroot の順に高速な結果となった。Brent法は二分法の安定性と補間法の高速性を組み合わせた手法であり、本例のように価格関数が利回りに対して滑らかで単調な問題では特に有効である。一方、ニュートン・ラフソン法は解析微分を必要とするものの高い収束性能を持ち、二分法は計算速度では劣るものの安定性に優れる。polyrootは規則的なキャッシュフローでは利用できるが、本例の40年債では80次多項式となるため計算負荷が大きくなる。

GaussQuantも同じ40年債、同じクリーンプライスを入力としている。ただし、単純な価格式だけを解く自作アルゴリズムとは異なり、債券オブジェクト、利払スケジュール、日数計算規則、価格種別などのマーケットコンベンションを含めて処理する。そのため、速度差には求根法そのものの差だけでなく、実務的な債券評価処理のオーバーヘッドも含まれる。

したがって、数値解法の選択では単純な計算速度だけでなく、収束速度、安定性、微分計算の可否、マーケットコンベンションへの対応を含めて評価することが重要である。この考え方は、後続章で扱う金利カーブのブートストラップ、インプライド・ボラティリティ、モデル・キャリブレーションにも共通する。
