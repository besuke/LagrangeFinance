第III-6章 自動微分による多変数金利感応度の計測

前章では、European OptionをGaussQuantとMonte Carlo + torchで評価し、Delta、Gamma、Vega、ThetaをAutomatic Differentiationから取得した。OptionではRisk Factorの数が比較的少なかったが、金利商品ではYield Curve上の多数のNodeが同時に価格へ影響する。

本章では、自動微分を金利商品へ拡張する。

Optionでは、

\[ V = V(S,\sigma,T,\ldots) \]

という少数のリスクファクターを扱った。

一方、金利商品では、価格は一つの金利だけでなく、 Yield Curve上の多数の点に依存する。

\[ V = V(r_1,r_2,\ldots,r_n) \]

したがって、金利リスク計測では、

\[ \frac{\partial V}{\partial r} \]

という一つの感応度から、

\[ \nabla_{\mathbf r}V = \left( \frac{\partial V}{\partial r_1}, \frac{\partial V}{\partial r_2}, \ldots, \frac{\partial V}{\partial r_n} \right) \]

というCurve全体のGradientへ進む必要がある。

本章では、まず単一のフラット金利を用いたSwapのDV01を計算し、 その後、複数ノードを持つYield Curveへ拡張する。

最終的に、

\[ \boxed{ \text{DV01} \longrightarrow \text{Bucketed DV01} \longrightarrow \text{GPS} \longrightarrow \text{Curve Gradient} } \]

という流れを、自動微分によって統一的に捉える。

III-6.1 金利商品の現在価値と感応度

将来キャッシュフロー\(CF_i\)の現在価値は、

\[ V = \sum_{i=1}^{n} CF_iD(0,t_i) \]

である。

単純化して、連続複利のフラット金利\(r\)を用いると、

\[ D(0,t_i) = e^{-rt_i} \]

なので、

\[ \boxed{ V(r) = \sum_{i=1}^{n} CF_i(r)e^{-rt_i} } \]

となる。

ここで重要なのは、金利商品では割引係数だけでなく、 キャッシュフロー自身も金利に依存する場合があることである。

したがって、

\[ \frac{\partial V}{\partial r} = \sum_i \left[ \frac{\partial CF_i}{\partial r}D_i + CF_i\frac{\partial D_i}{\partial r} \right] \]

となる。

これは、金利リスクが単なるDiscounting Riskではなく、 Projected Cash Flowの変化も含むことを意味する。

III-6.1.1 固定レグ

元本\(N\)、固定金利\(K\)、Accrual Factor \(\alpha_i\)とすると、 固定レッグのキャッシュフローは、

\[ CF_i^{\mathrm{fix}} = NK\alpha_i \]

である。

したがって、

\[ PV_{\mathrm{fix}} = \sum_i NK\alpha_i e^{-rt_i} \]

となる。

\(r\)で微分すると、

\[ \boxed{ \frac{\partial PV_{\mathrm{fix}}}{\partial r} = - \sum_i t_iNK\alpha_i e^{-rt_i} } \]

である。

金利が上昇すると割引係数が低下するため、 Fixed Legの現在価値は低下する。

III-6.1.2 変動レグ

本章では、自動微分の仕組みを明確にするため、 Floating Couponを単純化して、

\[ CF_i^{\mathrm{float}}(r) = N \left( e^{r\alpha_i} - 1 \right) \]

とする。

このとき、

\[ PV_{\mathrm{float}} = \sum_i N \left( e^{r\alpha_i} - 1 \right) e^{-rt_i} \]

である。

微分すると、

\[ \frac{\partial PV_{\mathrm{float}}}{\partial r} = \sum_i N e^{-rt_i} \left[ \alpha_i e^{r\alpha_i} - t_i \left( e^{r\alpha_i}-1 \right) \right] \]

となる。

Floating Legでは、

\[ \boxed{ \text{Projected Cash Flow Risk} + \text{Discounting Risk} } \]

の両方が金利感応度に含まれる。

III-6.1.3 スワップの現在価値

Receive Float / Pay Fixed Swapを考える。

\[ \boxed{ V_{\mathrm{swap}} = PV_{\mathrm{float}} - PV_{\mathrm{fixed}} } \]

したがって、

\[ \boxed{ \frac{\partial V_{\mathrm{swap}}}{\partial r} = \frac{\partial PV_{\mathrm{float}}}{\partial r} - \frac{\partial PV_{\mathrm{fixed}}}{\partial r} } \]

となる。

III-6.2 単一金利に対する感応度

DV01は、金利が1bp変化したときの価格変化を表す。

1bpは、

\[ 1\text{bp} = 10^{-4} \]

なので、微分による局所近似では、

\[ \boxed{ DV01 \approx \frac{\partial V}{\partial r} \times 10^{-4} } \]

となる。

符号については、業務システムやポジション表示の慣行により 異なる場合があるため、本章では

\[ \frac{\partial V}{\partial r}\times10^{-4} \]

をsigned DV01として扱う。

III-6.5 有限差分法による検証

同じSwap価格を通常のR関数として定義する。

swap_value_flat <- function(
    rate,
    notional,
    fixed_rate,
    payment_time,
    accrual
) {
  df <- exp(
    -rate * payment_time
  )

  fixed_cf <- notional *
    fixed_rate *
    accrual

  float_cf <- notional *
    (
      exp(
        rate * accrual
      ) -
        1
    )

  sum(
    float_cf * df
  ) -
    sum(
      fixed_cf * df
    )
}

1bp BumpによるForward Differenceを計算する。

bump <- 1e-4

base_npv <- swap_value_flat(
  rate = rate_value,
  notional = notional,
  fixed_rate = fixed_rate,
  payment_time = payment_time,
  accrual = accrual
)

up_npv <- swap_value_flat(
  rate = rate_value + bump,
  notional = notional,
  fixed_rate = fixed_rate,
  payment_time = payment_time,
  accrual = accrual
)

fd_dv01 <- up_npv - base_npv

fd_dv01
#> [1] 46634.17

Central Differenceによる一次微分も確認する。

down_npv <- swap_value_flat(
  rate = rate_value - bump,
  notional = notional,
  fixed_rate = fixed_rate,
  payment_time = payment_time,
  accrual = accrual
)

fd_dv_dr <- (
  up_npv -
    down_npv
) / (
  2 * bump
)

fd_dv01_central <- fd_dv_dr *
  1e-4

tbl_dv01_comparison <- tribble(
  ~method, ~dv01,
  "Forward bump", fd_dv01,
  "Central difference", fd_dv01_central,
  "Automatic differentiation", rate$grad$item() * 1e-4
)

tbl_dv01_comparison
#> # A tibble: 3 × 2
#>   method                      dv01
#>   <chr>                      <dbl>
#> 1 Forward bump              46634.
#> 2 Central difference        46646.
#> 3 Automatic differentiation 46646.

有限差分では価格を複数回評価する必要があるのに対し、 自動微分では構築された計算グラフを利用して感応度を得る。

III-6.6 多変数金利感応度への拡張

実際の金利市場では、単一の金利\(r\)ではなく、 満期ごとに異なる金利を持つ。

例えば、

\[ \mathbf r = (r_1,r_2,\ldots,r_n) \]

とする。

価格は、

\[ \boxed{ V = V(r_1,r_2,\ldots,r_n) } \]

となる。

したがって必要なのはScalar Derivativeではなく、

\[ \boxed{ \nabla_{\mathbf r}V = \left( \frac{\partial V}{\partial r_1}, \frac{\partial V}{\partial r_2}, \ldots, \frac{\partial V}{\partial r_n} \right) } \]

というGradientである。

各成分を1bpへ換算すれば、

\[ \boxed{ DV01_i = \frac{\partial V}{\partial r_i} \times10^{-4} } \]

となる。

これがBucketed DV01やPoint Sensitivityの基本になる。

III-6.11 GPSとしてのPoint Sensitivity

本章では、Yield Curve上の各Grid Pointに対する価格感応度を GPS（Grid Point Sensitivity）として扱う。

各Grid Point\(r_i\)に対して、

\[ \boxed{ GPS_i = \frac{\partial V}{\partial r_i} } \]

である。

1bp単位で表示する場合は、

\[ \boxed{ GPS01_i = GPS_i \times10^{-4} } \]

となる。

したがって、

\[ \mathbf{GPS} = \left( \frac{\partial V}{\partial r_1}, \ldots, \frac{\partial V}{\partial r_n} \right) \]

は、数学的にはそのままCurve Gradientである。

tbl_gps <- tbl_bucketed_dv01 |>
  transmute(
    tenor,
    grid_rate = rate,
    gps = sensitivity,
    gps01 = dv01
  )

tbl_gps
#> # A tibble: 5 × 4
#>   tenor grid_rate         gps      gps01

この考え方によって、

\[ \boxed{ \text{DV01} = \text{Scalar Risk} } \]

から、

\[ \boxed{ \text{GPS} = \text{Vector Risk} } \]

へ拡張できる。

ただし、実務ではCurve Construction、Interpolation、 複数Curve、Quote Mappingなどが存在するため、

\[ \text{Parallel DV01} = \sum_i \text{Bucketed DV01}_i \]

が常に厳密に成立するとは限らない。

重要なのは、各リスクファクターに対する局所感応度を Gradientとして保持することである。

III-6.13 Market QuoteからCurve Riskへ

実務の金利リスクでは、直接Zero RateをBumpするだけでは不十分である。

実際の計算は、

\[ \text{Market Quotes} \rightarrow \text{Bootstrap} \rightarrow \text{Yield Curve} \rightarrow \text{Discount Factors} \rightarrow \text{Cash Flows} \rightarrow V \]

という計算グラフを持つ。

Market Quoteを、

\[ \mathbf q = (q_1,q_2,\ldots,q_m) \]

Yield Curve Nodeを、

\[ \mathbf r = (r_1,r_2,\ldots,r_n) \]

とすると、

\[ V = V \left( \mathbf r(\mathbf q) \right) \]

である。

連鎖律より、

\[ \boxed{ \frac{\partial V}{\partial q_j} = \sum_i \frac{\partial V}{\partial r_i} \frac{\partial r_i}{\partial q_j} } \]

となる。

行列表現では、

\[ \boxed{ \nabla_{\mathbf q}V = J_{\mathbf r,\mathbf q}^{T} \nabla_{\mathbf r}V } \]

である。

ここで、

\[ J_{\mathbf r,\mathbf q} \]

はMarket QuoteからCurve NodeへのJacobianである。

この式は、金利リスク計測とAutomatic Differentiationをつなぐ 重要な関係である。

III-6.14 Multi-Curveへの拡張

実際のSwapでは、Discount CurveとForward Curveを分離する Multi-Curve Frameworkが一般的である。

この場合、価格は、

\[ V = V \left( \mathbf r^{disc}, \mathbf r^{fwd} \right) \]

と表される。

したがって、

\[ \nabla V = \left( \nabla_{\mathbf r^{disc}}V, \nabla_{\mathbf r^{fwd}}V \right) \]

となる。

すなわち、

\[ \boxed{ \text{Discount Risk} + \text{Forward Risk} } \]

を別々のGradientとして取得できる。

これは次章で扱うPRDCに直接つながる。

PRDCでは、

\[ \text{JPY Curve} + \text{Foreign Curve} + \text{FX} \]

という複数のリスクファクターを同時に扱うためである。

III-6.15 自動微分による金利リスク計測の意味

有限差分によるBucketed Riskでは、 Curve Nodeの数だけBump & Revalueを繰り返す必要がある。

例えば100個のCurve Nodeに対してCentral Differenceを使えば、

\[ 2\times100 = 200 \]

回の再評価が必要になる。

一方、自動微分では、

\[ V = V(r_1,r_2,\ldots,r_{100}) \]

という計算グラフを構築し、

\[ V \longrightarrow \nabla_{\mathbf r}V \]

と逆伝播する。

したがって、金利リスク計測は、

Yield Curve
r1 r2 r3 ... rn
 \  |  |     /
  \ |  |    /
 Pricing Graph
      |
      v
     NPV
      |
      | backward()
      v
dV/dr1 ... dV/drn

として捉えることができる。

これは、

\[ \boxed{ \text{Scalar Pricing} \longrightarrow \text{Vector Risk} } \]

への変換である。

III-6.16 まとめ

本章では、Option Greeksで確認した自動微分を 金利商品へ拡張した。

まず単一のフラット金利について、

\[ V=V(r) \]

から、

\[ \boxed{ DV01 = \frac{\partial V}{\partial r} \times10^{-4} } \]

を求めた。

次にYield Curveを、

\[ \mathbf r = (r_1,\ldots,r_n) \]

というTensorとして扱い、

\[ \boxed{ \nabla_{\mathbf r}V = \left( \frac{\partial V}{\partial r_1}, \ldots, \frac{\partial V}{\partial r_n} \right) } \]

を一度のReverse Mode Automatic Differentiationで取得した。

これにより、

\[ \boxed{ \text{DV01} \rightarrow \text{Bucketed DV01} \rightarrow \text{GPS} \rightarrow \text{Curve Gradient} } \]

という金利リスク計測を統一的に表現できる。

さらに、

\[ \text{Market Quote} \rightarrow \text{Curve} \rightarrow \text{PV} \]

という計算グラフに対して連鎖律を適用すれば、 Market Quote単位のRiskへ拡張できる。

次章では、この考え方をPRDCへ適用する。

PRDC価格を、

\[ V = V \left( S_{FX}, \mathbf r_{JPY}, \mathbf r_{Foreign}, \sigma_{FX}, \ldots \right) \]

と表し、

\[ \boxed{ \Delta_{FX}, \quad \mathbf{DV01}_{JPY}, \quad \mathbf{DV01}_{Foreign}, \quad Vega_{FX} } \]

を同じComputational Graphから計算する。

これにより、第III部の最終段階として、 為替と複数金利カーブを持つ多因子商品の Differentiable Risk Engineを構築する。
