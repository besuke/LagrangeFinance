第III-7章 多因子モンテカルロの自動微分による市場リスク感応度計測

第III部では、二つの方向からクオンツ計算の高度化を進めてきた。前半ではParallel / Distributed Computingによって大量のPricingを処理する計算基盤を構築し、後半ではPricingそのものをDifferentiable Computational Graphとして設計することで、Automatic DifferentiationからRisk Sensitivityを直接取得した。

最終章では、この二つの考え方が同時に必要となる代表例としてPRDCを扱う。PRDCはFX、複数通貨のYield Curve、Volatilityなど多数のRisk Factorを持ち、価格評価にはMonte Carlo Simulationが必要となる。したがって、大規模計算をどう実行するかと、多数の感応度をどう効率的に生成するかという第III部の二つの課題が一つの商品に集約される。

第III-5章ではOption Greeks、第III-6章ではDV01からCurve Gradientへと、価格関数の入力次元を段階的に増やしてきた。本章ではさらに、

\[ V = V \left( S_{FX}, \mathbf r_{JPY}, \mathbf r_{Foreign}, \sigma_{FX} \right) \]

という多因子Monte Carlo Pricingを一つの計算Graphとして構成し、

\[ \boxed{ \Delta_{FX}, \quad \mathbf{DV01}_{JPY}, \quad \mathbf{DV01}_{Foreign}, \quad Vega_{FX} } \]

を一度のReverse-mode Automatic Differentiationから取得する。

本章の目的は、単にPRDCのGreeksを計算することではない。Monte Carlo PricingとRisk Calculationを別々の処理として繰り返すのではなく、PricingそのものからRiskを生成するというDifferentiable Risk Engineの設計を示すことである。

III-7.1 多因子市場モデル

III-7.1.1 市場リスクファクター

PRDCは、為替と複数通貨の金利を同時に扱うハイブリッド商品である。

単純なOptionでは、

\[ V=V(S,\sigma,r,T) \]

と少数の入力変数を考えればよかった。

PRDCでは、

FX Spot
   |
   +-------------------+
   |                   |
   v                   v
FX Process        Coupon Formula
   ^
   |
JPY Rates <----> Foreign Rates
   |                   |
   v                   v
Discounting       FX Drift / Forward
   \                   /
    \                 /
     ------ PRDC ------
             |
             v
            NPV

という複数の経路から価格が構成される。

したがって、一つの市場変数を変更した場合でも、 その影響は複数の計算経路を通って最終価格へ伝わる。

例えばJPY金利は、

  • JPY Discount Factor
  • FXのRisk-Neutral Drift
  • 将来Couponの期待値

へ影響する。

Foreign Rateも、

  • FX Forward
  • FXのRisk-Neutral Drift
  • 将来Couponの期待値

へ影響する。

このような商品では、連鎖律をプログラム全体へ適用する Automatic Differentiationの考え方が特に重要になる。

III-7.1.2 為替連動クーポン

PRDCには多様なCoupon構造、Callable条件、Notional Exchange、 Target Redemption、Barrierなどが存在する。

本章では自動微分の構造を明確にするため、 第II部・第III部で扱ったPRDCの考え方を簡略化し、 為替連動Couponを、

\[ c_i = \min \left[ c_{\max}, \max \left( 0, c_0 + L \left( \frac{S_i}{S_{\mathrm{ref}}} - 1 \right) \right) \right] \]

とする。

ここで、

  • \(c_0\)：Base Coupon
  • \(L\)：FX Leverage
  • \(S_i\)：Coupon DateのFX Spot
  • \(S_{\mathrm{ref}}\)：Reference FX
  • \(c_{\max}\)：Coupon Cap

である。

Coupon Cash Flowは、

\[ CF_i = N\alpha_i c_i \]

とする。

このPayoffはAutomatic Differentiationの構造を明確にするための教育用モデルである。実際のPRDCではCoupon Formula、Callable条件、Notional Exchangeなどを追加する必要があるが、重要なのは、それらを同じDifferentiable Computational Graphの中へ組み込めることである。

重要なのはPayoffの具体的な形ではなく、

\[ \boxed{ \text{FX} + \text{JPY Curve} + \text{Foreign Curve} + \text{Volatility} \longrightarrow \text{PRDC NPV} } \]

という計算グラフを微分可能な演算として構成することである。

III-7.1.3 為替のリスク中立過程

JPYをDomestic Currency、 Foreign Currencyを外貨とする。

簡略化したLognormal FX Processとして、

\[ \frac{dS_t}{S_t} = \left( r_{JPY}(t) - r_{Foreign}(t) \right)dt + \sigma_{FX}dW_t \]

を用いる。

離散化すると、

\[ S_{t+\Delta t} = S_t \exp \left[ \left( r_{JPY} - r_{Foreign} - \frac12\sigma_{FX}^2 \right)\Delta t + \sigma_{FX}\sqrt{\Delta t}Z \right] \]

となる。

ここで、

\[ Z\sim N(0,1) \]

である。

この式から、FX Path自身が、

\[ S_{t_i} = S_{t_i} \left( S_0, \mathbf r_{JPY}, \mathbf r_{Foreign}, \sigma_{FX}, Z \right) \]

という関数になっていることが分かる。

したがってPRDC価格を微分すると、 CouponだけではなくFX Path生成まで連鎖律が伝播する。

III-7.2 多因子モンテカルロによる価格評価

PRDCのMonte Carlo価格を、

\[ \hat V = \frac{1}{M} \sum_{m=1}^{M} \left[ \sum_{i=1}^{n} D_{JPY}(0,t_i) CF_i^{(m)} + D_{JPY}(0,T)N \right] \]

とする。

ここで、

\[ M \]

はPath数である。

JPY Discount Factorは、期間ごとの短期金利を用いて、

\[ D_{JPY}(0,t_i) = \exp \left[ - \sum_{j=1}^{i} r_{JPY,j}\Delta t_j \right] \]

とする。

したがって計算全体は、

JPY Curve --------+
                  |
Foreign Curve ----+----> FX Paths
                  |         |
FX Spot ----------+         v
                  |      Coupons
FX Vol -----------+         |
                            v
JPY Curve ------------> Discount Factors
                            |
                            v
                         PRDC NPV

となる。

III-7.2.3 微分可能なプライシング

PRDCのMonte Carlo Pricingを、 Tensor演算だけで構成する。

prdc_price_torch <- function(
    fx_spot,
    jpy_curve,
    foreign_curve,
    fx_vol,
    z,
    notional,
    reference_fx,
    fixed_coupon,
    leverage,
    coupon_cap,
    dt
) {
  drift_step <- (
    jpy_curve -
      foreign_curve -
      0.5 * fx_vol^2
  ) * dt

  diffusion_step <- fx_vol *
    torch_sqrt(dt) *
    z

  log_fx_path <- torch_log(
    fx_spot
  ) +
    torch_cumsum(
      drift_step +
        diffusion_step,
      dim = 2
    )

  fx_path <- torch_exp(
    log_fx_path
  )

  raw_coupon_rate <- fixed_coupon +
    leverage * (
      fx_path / reference_fx -
        1
    )

  coupon_rate <- torch_minimum(
    torch_maximum(
      raw_coupon_rate,
      torch_zeros_like(raw_coupon_rate)
    ),
    coupon_cap
  )

  coupon_cf <- notional *
    coupon_rate *
    dt

  discount_factor <- torch_exp(
    -torch_cumsum(
      jpy_curve * dt,
      dim = 1
    )
  )

  pv_coupon <- torch_sum(
    coupon_cf *
      discount_factor,
    dim = 2
  )

  pv_redemption <- notional *
    discount_factor[n_steps]

  torch_mean(
    pv_coupon +
      pv_redemption
  )
}

この関数の中では、

  • FX Path生成
  • Coupon計算
  • JPY Discounting
  • Monte Carlo Average

のすべてがTensor演算として接続されている。

したがって、最終的なprdc_npvから、 入力された市場リスクファクターまで計算グラフが維持される。

III-7.3 自動微分による多因子感応度

Forward計算で得られたScalar NPVを出発点として、複数の市場入力へGradientを逆伝播させる。PRDCのように「多数入力・少数出力」となるPricingでは、Reverse Modeの利点が最も現れやすい。

prdc_grad <- autograd_grad(
  outputs = prdc_npv,
  inputs = list(
    fx_spot_t,
    jpy_curve_t,
    foreign_curve_t,
    fx_vol_t
  )
)

fx_delta_t <- prdc_grad[[1]]
jpy_rate_grad_t <- prdc_grad[[2]]
foreign_rate_grad_t <- prdc_grad[[3]]
fx_vega_t <- prdc_grad[[4]]

ここで、

\[ fx\_delta = \frac{\partial V}{\partial S_{FX}} \]

\[ jpy\_rate\_grad_i = \frac{\partial V}{\partial r_{JPY,i}} \]

\[ foreign\_rate\_grad_i = \frac{\partial V}{\partial r_{Foreign,i}} \]

\[ fx\_vega = \frac{\partial V}{\partial\sigma_{FX}} \]

である。

III-7.3.1 FXデルタ

FX Deltaは、

\[ \boxed{ \Delta_{FX} = \frac{\partial V}{\partial S_{FX}} } \]

である。

fx_delta <- fx_delta_t$item()

fx_delta
#> [1] 473469.3

PRDCのCoupon構造によって、 FX Deltaの符号や大きさは大きく変化する。

本章の簡略PayoffではFX上昇によってCouponが増加する形を用いているが、 実際のPRDCではCurrency Pairの定義やCoupon Formulaによって 感応度の符号は異なる。

III-7.3.2 円金利リスク

JPY Curveの各Nodeに対する感応度は、

\[ \boxed{ \frac{\partial V} {\partial r_{JPY,i}} } \]

である。

1bp単位へ換算すると、

\[ \boxed{ DV01_{JPY,i} = \frac{\partial V} {\partial r_{JPY,i}} \times10^{-4} } \]

となる。

    jpy_rate_grad_t

    dv01 = sensitivity * 1e-4

\[ \frac{\partial V} {\partial r_{JPY,i}} \]

には、

\[ \boxed{ \text{JPY Discount Risk} + \text{FX Drift Risk} + \text{Coupon Risk} } \]

が連鎖律を通じて含まれる。

III-7.3.4 FXベガ

FX Volatilityに対する感応度は、

\[ \boxed{ Vega_{FX} = \frac{\partial V} {\partial\sigma_{FX}} } \]

である。

fx_vega <- fx_vega_t$item()

fx_vega
#> [1] 40120812

Volatilityを1 percentage point、 すなわち0.01だけ変化させた場合の近似価格変化として、

\[ Vega01_{FX} = \frac{\partial V} {\partial\sigma_{FX}} \times0.01 \]

を定義することもできる。

fx_vega_01 <- fx_vega * 0.01

fx_vega_01
#> [1] 401208.1

PRDCのCouponにはFloorやCapが存在するため、 Volatilityの変化は単純な線形効果ではない。

Monte Carlo Pathの分布が変化し、 FloorやCapへ到達するPathの割合も変化する。

自動微分では、このPath生成からPayoffまでの連鎖を 同じ計算グラフの中で扱う。

これにより、一つのPRDC価格から、

\[ \boxed{ \nabla V = \left( \Delta_{FX}, \mathbf{DV01}_{JPY}, \mathbf{DV01}_{Foreign}, Vega_{FX} \right) } \]

を取得したことになる。

III-7.5 微分不可なペイオフのケース

本章のCouponでは、

\[ \max(0,x) \]

および、

\[ \min(c_{\max},x) \]

を使用している。

これらの関数はKinkを持ち、 境界点では通常の意味で微分不可能である。

torch_minimum()やtorch_maximum()などのTensor演算は、 こうした演算について実装上定義された局所Gradientを使用して Reverse Modeを実行する。

Monte Carloでは、連続分布のもとでPathがKinkへ 厳密に一致する確率は通常ゼロであるため、 Pathwise Derivativeを利用できる場合が多い。

ただし、Digital Payoff、Barrier Hit Indicator、 Exercise Decisionなど不連続性の強い商品では、 単純なPathwise Automatic Differentiationだけでは 安定した感応度が得られない場合がある。

その場合には、

  • Smoothing
  • Likelihood Ratio Method
  • Conditional Expectation
  • Pathwise / LRM Hybrid
  • Differentiable Approximation

などを検討する必要がある。

これは、Automatic Differentiationが 「あらゆる金融商品をそのまま微分すればよい」 という意味ではないことを示している。

III-7.5.2 微分不可なペイオフの感応度

PRDCのような商品では、

\[ \hat V = \frac{1}{M} \sum_{m=1}^{M} V^{(m)} \]

というMonte Carlo Averageを微分する。

条件が整えば、

\[ \frac{\partial}{\partial x} E \left[ V(x,Z) \right] = E \left[ \frac{\partial V(x,Z)} {\partial x} \right] \]

と考えることができる。

つまり各PathのPricing Calculationを微分可能に構成すれば、 そのAverageであるMonte Carlo Priceについても Automatic Differentiationを適用できる。

この考え方が、

\[ \boxed{ Monte\ Carlo + Automatic\ Differentiation } \]

を結び付ける。

III-7.6 大規模市場リスク計測への展開

第III-1章で確認したように、 Monte CarloはGPUと相性が良い。

本章の実装でも、

z

は、

\[ M\times n \]

のTensorであり、 FX Path全体をLoopではなくTensor演算として計算している。

したがって計算デバイスをGPUへ移せる環境では、

\[ \boxed{ Monte\ Carlo + GPU + Automatic\ Differentiation } \]

という組み合わせが可能になる。

ここで重要なのは、 GPUによるHardware Accelerationと、 Automatic DifferentiationによるAlgorithmic Accelerationが 同じTensor計算基盤の上で共存できることである。

III-7.6.2 自動微分による多因子感応度の一括計算

PRDCのPricing Graphをもう一度整理する。

FX Spot -----------+
JPY Curve ---------+----> FX Paths ----> Coupons ----+
Foreign Curve -----+                                 |
FX Vol ------------+                                 v
JPY Curve --------------------> Discount Factors -> PRDC NPV
                                                      |
                                                      | Reverse Mode / AAD
                                                      v
                                  +-------------------+-------------------+
                                  |                   |                   |
                              FX Delta           JPY DV01          Foreign DV01
                                  |                                       |
                                  +---------------- FX Vega ---------------+

Forward計算では、

\[ \text{Risk Factors} \longrightarrow \text{PRDC NPV} \]

を求める。

Reverse計算では、

\[ \text{PRDC NPV} \longrightarrow \text{Risk Factors} \]

へ勾配を伝播する。

このForwardとReverseの組み合わせが、 PRDCをDifferentiable Pricing Modelとして扱うという意味である。

III-7.6.3 エンタープライズ・リスク計算への展開

第III部で扱った商品を並べると、 自動微分の役割が明確になる。

オプション

\[ V = V(S,\sigma,T) \]

\[ \Downarrow \]

\[ \Delta,\quad \Gamma,\quad Vega,\quad Theta \]

金利商品

\[ V = V(r_1,r_2,\ldots,r_n) \]

\[ \Downarrow \]

\[ DV01,\quad Bucketed\ DV01,\quad GPS \]

金利為替系デリバティブ

\[ V = V \left( S_{FX}, \mathbf r_{JPY}, \mathbf r_{Foreign}, \sigma_{FX} \right) \]

\[ \Downarrow \]

\[ \boxed{ \Delta_{FX}, \quad \mathbf{DV01}_{JPY}, \quad \mathbf{DV01}_{Foreign}, \quad Vega_{FX} } \]

つまり、商品が複雑になっても基本的な数学は変わらない。

\[ \boxed{ \text{Risk} = \text{Derivative of Price} } \]

である。

変わるのは、価格関数を構成するComputational Graphの規模である。

III-7.7 まとめ

本章では、PRDCを題材として、FX Spot、JPY Curve、Foreign Curve、FX Volatilityを同時に持つ多因子Monte Carlo PricingをRのtorchで構成した。Pricing FunctionをTensor演算だけで接続することで、Monte Carlo Path生成、Coupon計算、Discounting、NPVまでを一つのDifferentiable Computational Graphとして扱うことができた。

その結果、一度のForward PricingとReverse Passから、

\[ \boxed{ \nabla V = \left( \Delta_{FX}, \mathbf{DV01}_{JPY}, \mathbf{DV01}_{Foreign}, Vega_{FX} \right) } \]

を取得した。ここで重要なのは、Risk FactorごとにPricing Engineを何度も呼び出すBump & Revalueから、Pricing GraphそのものがRiskを生成する構造へ移行したことである。

第III部全体を振り返ると、前半ではfuture / furrrを中心にTaskを分割し、複数Core・複数Worker・分散環境へ計算を配布する方法を扱った。これは計算資源を増やすことによるHardware / Infrastructure Accelerationである。後半ではtorchを用いて、価格計算にReverse-mode Automatic Differentiationを組み込み、感応度計算の方法そのものを変えた。これはAlgorithmic Accelerationである。

したがって、第III部の到達点は単なるParallel Computingでも、Automatic Differentiationの数式例でもない。大量のPricingを柔軟な計算資源へ配布し、そのPricing Graphから多数のRisk Sensitivityを同時に生成できる計算基盤である。

\[ \boxed{ \text{Scale Up / Scale Out} + \text{Automatic Differentiation} = \text{Enterprise Differentiable Risk Engine} } \]

これが、非同期並列化と自動微分を組み合わせたクオンツのエンタープライズ実装である。
